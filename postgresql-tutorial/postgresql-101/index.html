CREATE TABLE: identity column

PostgreSQL-এ auto-increment-এর আধুনিক উপায় GENERATED ALWAYS AS IDENTITY (পুরনো serial-ও চলে)। লেখার জন্য সাধারণত text — দৈর্ঘ্যের সীমা না দিলেও চলে, গতিতেও পার্থক্য নেই।

PostgreSQL
CREATE TABLE customers (
    id         bigint GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
    name       text NOT NULL,
    phone      varchar(15) NOT NULL,
    district   text,
    created_at timestamp NOT NULL DEFAULT now()
);
ফলাফল

LIKE বনাম ILIKE

PostgreSQL-এ LIKE ছোট-বড় হাতের অক্ষর আলাদা ধরে (MySQL ধরে না)। ছোট-বড় না মানতে ILIKE।

⚠️ MySQL থেকে Laravel app সরালে search হঠাৎ কাজ না করার সবচেয়ে বড় কারণ এটা। Laravel-এ where('name', 'ilike', ...) অথবা whereLike(..., caseSensitive: false)।

Type নিয়ে কঠোরতা

MySQL অনেক সময় নীরবে type বদলে নেয়। PostgreSQL সোজা error দেয় — ভুল আগেই ধরা পড়ে।

❓ 7 / 2 কেন ৩?

দুটোই integer, তাই integer ভাগ — দশমিক চাইলে একটাকে numeric দিন: 7 / 2.0 বা 7::numeric / 2।

PostgreSQL
SELECT name FROM products WHERE price = 'free';
Database বলছে (ইচ্ছাকৃত ভুল)
ERROR:  invalid input syntax for type numeric: "free"
LINE 1: SELECT name FROM products WHERE price = 'free';
                                                ^
PostgreSQL
SELECT 'Stock: ' || 5 AS ok, 7 / 2 AS int_div, 7 / 2.0 AS decimal_div;
ফলাফল

timestamp বনাম timestamptz

timestamptz সময়কে UTC-তে রাখে আর দেখানোর সময় session-এর timezone-এ বদলায়। Bangladesh (UTC+6) থেকে দেখলে ঠিক স্থানীয় সময়।

PHP/Laravel-এ যেমন Laravel-এ $table->timestampsTz() আর config/app.php-এর timezone। একাধিক দেশের user হলে সবসময় timestamptz।
PostgreSQL
SET timezone = 'Asia/Dhaka';
SELECT timestamptz '2026-10-21 10:00:00+00' AS utc_10am_in_dhaka;

SET timezone = 'UTC';
SELECT timestamptz '2026-10-21 10:00:00+00' AS same_moment_in_utc;

Backup আর restore

  • -Fc — compressed custom format; pg_restore দিয়ে বাছাই করে restore করা যায়
  • শুধু SQL চাইলে: pg_dump shop > shop.sql
  • শুধু গঠন: pg_dump --schema-only
Terminal
$ pg_dump -Fc shop > shop.dump
$ createdb shop_copy
$ pg_restore -d shop_copy shop.dump
