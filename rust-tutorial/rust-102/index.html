Ownership ও Data

এই কোর্সটাই Rust-এর হৃদয়। Ownership বুঝলে বাকি Rust সহজ। তারপর struct আর enum দিয়ে নিজের data type বানাব।

  • Stack, heap আর ownership-এর ৩ নিয়ম
  • Move, clone আর Copy
  • Borrowing: & আর &mut
  • String, &str আর বাংলা লেখা
  • struct, impl আর method
  • enum, Option (null নেই!)
  • Vec আর HashMap
  • Result আর ? দিয়ে error সামলানো

আগে জানা দরকার: Rust 101 (variable, function, if, loop, match)।

পাঠ ১

Stack আর Heap

Program-এর data দুই জায়গায় থাকে। কোনটা কোথায় থাকে বুঝলে ownership বোঝা সহজ।

StackHeap
কী থাকেআকার জানা ছোট data: i32, bool, charআকার বদলায় এমন data: String, Vec
গতিখুব দ্রুতএকটু ধীর (খুঁজে জায়গা নিতে হয়)
কে পরিষ্কার করেfunction শেষ হলেইযে variable "মালিক", সে scope-এর বাইরে গেলে
PHP/Laravel-এ যেমন PHP-তে garbage collector আর reference count এই কাজ করে, আপনি টেরই পান না। Rust-এ GC নেই — compiler ownership নিয়ম দেখে ঠিক করে কখন memory ছাড়বে।
পাঠ ২

Ownership-এর ৩ নিয়ম

১প্রতিটি মানের একজন মালিক (owner) variable থাকে
২একসাথে মালিক একজনই
৩মালিক scope ({ })-এর বাইরে গেলে মানটা drop হয়, memory ফেরত যায়
💡 এই তিনটা নিয়মই পুরো কোর্সের ভিত্তি। বাকি সব এগুলো থেকেই আসে।
Rust
fn main() {
    {
        let shop = String::from("Rahim Mobile");  // shop মালিক
        println!("ভিতরে: {shop}");
    }   // এখানে shop drop হলো, memory ফেরত

    // println!("{shop}");  // এখানে shop আর নেই
    println!("block শেষ");
}
আউটপুট
ভিতরে: Rahim Mobile
block শেষ
পাঠ ৩

Move: মালিকানা হাতবদল

String এক variable থেকে আরেকটায় দিলে কপি হয় না — মালিকানা চলে যায় (move)। আগের variable আর ব্যবহার করা যায় না।

PHP/Laravel-এ যেমন PHP-তে $b = $a; করলে string কপি হয়, দুটোই চলে। Rust-এ String-এর জন্য এটা move।
❓ কেন Rust দুটোকেই চলতে দেয় না?

দুজন মালিক থাকলে scope শেষে দুজনই একই memory ছাড়তে চাইত (double free)। একজন মালিক মানে এই bug অসম্ভব।

Rust
fn main() {
    let s1 = String::from("Samsung A15");
    let s2 = s1;              // মালিকানা s2-তে গেল
    println!("{s2}");
    println!("{s1}");          // s1 এখন খালি
}
Compiler বলছে (ইচ্ছাকৃত ভুল)
error[E0382]: borrow of moved value: `s1`
 --> src/main.rs:5:16

4 |     println!("{s2}");
5 |     println!("{s1}");          // s1 এখন খালি

help: consider cloning the value if the performance cost is acceptable

  |                ++++++++
পাঠ ৪

clone: সত্যিকারের কপি

সত্যি দুটো আলাদা কপি চাইলে .clone()। এতে heap-এর data-ও কপি হয়, তাই বড় data-তে খরচ আছে।

💡 শুরুতে compile না হলে clone() দিয়ে চালিয়ে নেওয়া দোষের না। পরে borrowing শিখে অপ্রয়োজনীয় clone সরাবেন।
Rust
fn main() {
    let s1 = String::from("Samsung A15");
    let s2 = s1.clone();       // heap-এ নতুন কপি
    println!("s1 = {s1}, s2 = {s2}");
}
আউটপুট
s1 = Samsung A15, s2 = Samsung A15
পাঠ ৫

Copy type: সংখ্যা move হয় না

i32, f64, bool, char — এগুলো ছোট আর পুরোটাই stack-এ, তাই দিলে নিজে থেকেই কপি হয়। এদের বলে Copy type।

Copy (কপি হয়)Move (মালিকানা যায়)
i32, u64, f64, bool, charString, Vec, HashMap
শুধু Copy দিয়ে বানানো tuple: (i32, bool)এগুলো থাকা struct
Rust
fn main() {
    let price = 23500;
    let copy = price;          // কপি হলো, move না
    println!("{price} {copy}");

    let ok = true;
    let ok2 = ok;
    println!("{ok} {ok2}");
}
আউটপুট
23500 23500
true true
পাঠ ৬

Function-এ দিলেও move

Function-এ String পাঠালে মালিকানা function-এ চলে যায়। Function শেষে সেটা drop হয়।

সমাধান: মালিকানা না দিয়ে শুধু ধার (borrow) দেওয়া। পরের পাঠ।

Rust
fn print_invoice(customer: String) {
    println!("Invoice: {customer}");
}   // customer এখানে drop

fn main() {
    let name = String::from("Karim");
    print_invoice(name);
    println!("আবার: {name}");   // name তো চলে গেছে
}
Compiler বলছে (ইচ্ছাকৃত ভুল)

  |                   ---- value moved here
8 |     println!("আবার: {name}");   // name তো চলে গেছে
  |                     ^^^^ value borrowed here after move

পাঠ ৭

& দিয়ে ধার দেওয়া

&name মানে "দেখতে দিলাম, মালিকানা না"। Function-এর parameter হয় &String বা ভালো হলো &str।

PHP/Laravel-এ যেমন PHP object যেমন handle হিসেবে যায়, অনেকটা সেরকম — কিন্তু Rust-এ ধার নেওয়া জিনিস বদলানো যায় না (যদি না &mut হয়)।
Rust
fn print_invoice(customer: &str) {
    println!("Invoice: {customer}");
}

fn main() {
    let name = String::from("Karim");
    print_invoice(&name);       // ধার দিলাম
    print_invoice(&name);       // আবারও দেওয়া যায়
    println!("মালিক এখনো name: {name}");
}
আউটপুট
Invoice: Karim
Invoice: Karim
মালিক এখনো name: Karim
পাঠ ৮

&mut: বদলানোর জন্য ধার

Function-কে বদলানোর অনুমতি দিতে &mut। Variable-টাও mut হতে হবে।

PHP/Laravel-এ যেমন function addItem(array &$cart, $item) — PHP-র & reference-এর মতো।
Rust
fn add_item(cart: &mut Vec<String>, item: &str) {
    cart.push(item.to_string());
}

fn main() {
    let mut cart = Vec::new();
    add_item(&mut cart, "Charger");
    add_item(&mut cart, "Earphone");
    println!("Cart: {:?}", cart);
}
আউটপুট
Cart: ["Charger", "Earphone"]
পাঠ ৯

নিয়ম: একসাথে একটা &mut, অথবা অনেক &

একই সময়ে হয় অনেকে শুধু দেখবে (&), নয়তো একজন বদলাবে (&mut)। দুটো একসাথে না। এভাবেই Rust data race আটকায়।

💡 কেন? push-এ Vec নতুন জায়গায় সরে যেতে পারে, তখন first ভুল memory দেখাত। Compiler এটা আগেই আটকাল।
Rust
fn main() {
    let mut stock = vec![5, 3, 8];
    let first = &stock[0];        // দেখছি
    stock.push(10);               // বদলাচ্ছি — অথচ first এখনো ব্যবহার হবে
    println!("প্রথম: {first}");
}
Compiler বলছে (ইচ্ছাকৃত ভুল)
error[E0502]: cannot borrow `stock` as mutable because it is also borrowed as immutable
 --> src/main.rs:4:5
  |
3 |     let first = &stock[0];        // দেখছি
  |                  ----- immutable borrow occurs here
4 |     stock.push(10);               // বদলাচ্ছি — অথচ first এখনো ব্যবহার হবে
  |     ^^^^^^^^^^^^^^ mutable borrow occurs here
5 |     println!("প্রথম: {first}");
  |                      ----- immutable borrow later used here

Reference ঝুলে থাকতে পারে না

যে মান মরে যাবে তার reference ফেরত দেওয়া যায় না। PHP বা C-তে এই ধরনের bug চলার সময় ধরা পড়ে; Rust compile-এর সময়েই আটকায়।

সমাধান সহজ: reference না দিয়ে মালিকানাসহ String ফেরত দিন: fn make_name() -> String।

fn make_name() -> &String {

    &s

fn main() {

Slice: পুরোটা না, একটা অংশ ধার

&s[0..5] হলো String-এর একটা অংশের reference (&str)। Array/Vec-এর অংশ হলো &[T]।

💡 Function-এ text নিতে &str ব্যবহার করুন — তাহলে String আর "literal" দুটোই পাঠানো যায়।
Rust
fn first_word(s: &str) -> &str {
    match s.find(' ') {
        Some(i) => &s[..i],
        None => s,
    }
}

fn main() {
    let model = String::from("Xiaomi Redmi Note 13");
    println!("Brand: {}", first_word(&model));

    let sales = [1200, 3400, 2100, 5000];
    let last_two = &sales[2..];
    println!("শেষ দুই দিন: {:?}", last_two);
}
আউটপুট
Brand: Xiaomi
শেষ দুই দিন: [2100, 5000]

বাংলা লেখা: byte বনাম অক্ষর

Rust-এর String হলো UTF-8 byte। বাংলা অক্ষর সাধারণত ৩ byte। তাই len() byte গোনে, অক্ষর গুনতে chars().count()।

PHP/Laravel-এ যেমন PHP-তে strlen() byte গোনে, mb_strlen() অক্ষর — Rust-এ len() আর chars().count()।
Rust
fn main() {
    let word = "ঢাকা";
    println!("byte: {}", word.len());
    println!("char: {}", word.chars().count());
    for ch in word.chars() {
        print!("[{ch}] ");
    }
    println!();
}
আউটপুট
byte: 12
char: 4
[ঢ] [া] [ক] [া]

বাংলা কাটতে সাবধান

Byte index দিয়ে কাটলে অক্ষরের মাঝখানে পড়লে program panic করে। বাংলায় chars() দিয়ে কাজ করুন।

Rust
fn main() {
    let word = "ঢাকা";
    let first: String = word.chars().take(2).collect();
    println!("প্রথম ২ char: {first}");
    println!("{}", &word[0..2]);   // ২ byte = অক্ষরের মাঝখান
}

end byte index 2 is not a char boundary; it is inside 'ঢ' (bytes 0..3 of string)

struct: নিজের data type

কয়েকটা field একসাথে বেঁধে নতুন type বানাতে struct। PHP class-এর property অংশটুকুর মতো।

PHP/Laravel-এ যেমন class Product { public string $name; public int $price; } — Rust-এ data (struct) আর method (impl) আলাদা ব্লকে লেখা হয়।
Rust
struct Product {
    name: String,
    price: u32,
    stock: u32,
}

fn main() {
    let phone = Product {
        name: String::from("Redmi Note 13"),
        price: 23500,
        stock: 4,
    };
    println!("{} — {} টাকা — স্টক {}", phone.name, phone.price, phone.stock);
}
আউটপুট
Redmi Note 13 — 23500 টাকা — স্টক 4
পাঠ ১৫

impl: method যোগ করা

impl ব্লকে method লিখি। প্রথম parameter &self মানে "এই product টা" — PHP-র $this।

Rust
struct Product {
    name: String,
    price: u32,
    stock: u32,
}

impl Product {
    fn stock_value(&self) -> u32 {
        self.price * self.stock
    }

    fn is_low(&self) -> bool {
        self.stock < 3
    }
}

fn main() {
    let p = Product { name: "Vivo Y28".to_string(), price: 18000, stock: 2 };
    println!("{}: স্টকের দাম {} টাকা", p.name, p.stock_value());
    println!("স্টক কম? {}", p.is_low());
}
আউটপুট
Vivo Y28: স্টকের দাম 36000 টাকা
স্টক কম? true
পাঠ ১৬

new() আর &mut self

self ছাড়া function হলো associated function — Product::new() দিয়ে ডাকা হয়, PHP-র constructor বা static method-এর মতো। বদলাতে চাইলে &mut self।

PHP/Laravel-এ যেমন new Product('Realme') → Product::new("Realme")। Rust-এ new শুধু একটা নাম, বিশেষ keyword না।
Rust
struct Product {
    name: String,
    stock: u32,
}

impl Product {
    fn new(name: &str) -> Self {
        Self { name: name.to_string(), stock: 0 }
    }

    fn restock(&mut self, qty: u32) {
        self.stock += qty;
    }
}

fn main() {
    let mut p = Product::new("Realme C67");
    p.restock(5);
    p.restock(2);
    println!("{}: {}টা", p.name, p.stock);
}
আউটপুট
Realme C67: 7টা
পাঠ ১৭

#[derive(Debug)]: struct প্রিন্ট করা

{:?} দিয়ে struct প্রিন্ট করতে #[derive(Debug)] লাগে। {:#?} সুন্দর করে লাইন ভেঙে দেখায় — PHP-র dd()/print_r-এর মতো।

Rust
#[derive(Debug)]
struct Customer {
    name: String,
    phone: String,
    due: i64,
}

fn main() {
    let c = Customer {
        name: "Nusrat".into(),
        phone: "01711000000".into(),
        due: 1500,
    };
    println!("{:?}", c);
    println!("{:#?}", c);
    println!("{} ({}) এর বাকি {} টাকা", c.name, c.phone, c.due);
}
আউটপুট
Customer { name: "Nusrat", phone: "01711000000", due: 1500 }
Customer {
    name: "Nusrat",
    phone: "01711000000",
    due: 1500,
}
Nusrat (01711000000) এর বাকি 1500 টাকা

enum: কয়েকটার মধ্যে একটা

কোনো মান যদি নির্দিষ্ট কয়েকটার একটা হয় — যেমন payment-এর মাধ্যম — তাহলে enum।

PHP/Laravel-এ যেমন PHP 8.1-এর enum PaymentMethod { case Cash; case Bkash; } — খুব কাছাকাছি।
Rust
#[derive(Debug)]
enum PaymentMethod {
    Cash,
    Bkash,
    Nagad,
    Card,
}

fn fee_percent(m: &PaymentMethod) -> f64 {
    match m {
        PaymentMethod::Cash => 0.0,
        PaymentMethod::Bkash | PaymentMethod::Nagad => 1.5,
        PaymentMethod::Card => 2.0,
    }
}

fn main() {
    let all = [PaymentMethod::Cash, PaymentMethod::Bkash, PaymentMethod::Nagad, PaymentMethod::Card];
    for m in &all {
        println!("{:?}: চার্জ {}%", m, fee_percent(m));
    }
}

নিজের function থেকে Result

Rust
fn withdraw(balance: u32, amount: u32) -> Result<u32, String> {
    if amount == 0 {
        return Err("০ টাকা তোলা যায় না".to_string());
    }
    if amount > balance {
        return Err(format!("ব্যালেন্স কম: আছে {balance}, চাইছেন {amount}"));
    }
    Ok(balance - amount)
}

fn main() {
    let balance = 1000;
    for amount in [300, 0, 5000] {
        match withdraw(balance, amount) {
            Ok(left) => println!("{amount} তোলা হলো, বাকি {left}"),
            Err(msg) => println!("ব্যর্থ: {msg}"),
        }
    }
}

PHP/Laravel-এ যেমন Laravel-এ exception নিজে থেকেই উপরে উঠে handler-এ যায়। Rust-এ ? লিখে আপনি নিজে বলে দেন — কোথায় error উঠতে পারে, কোড পড়েই দেখা যায়।

use std::num::ParseIntError;

fn total(price: &str, qty: &str) -> Result<u32, ParseIntError> {
    let p: u32 = price.parse()?;   // ভুল হলে এখান থেকেই Err ফেরত
    let q: u32 = qty.parse()?;
    Ok(p * q)
}

fn main() {
    println!("{:?}", total("450", "3"));
    println!("{:?}", total("450", "তিন"));
}

Project: দোকানের Inventory

struct, enum, HashMap, Result আর ? একসাথে। প্রতিটি লাইন একটা command: add, sell, report।

নিজে করুন price যোগ করুন: add Redmi13 5 17500, আর report-এ মোট স্টকের দাম দেখান।
Rust
use std::collections::BTreeMap;
use std::io::{self, BufRead};

enum Command { Add(String, u32), Sell(String, u32), Report }

fn parse(line: &str) -> Result<Command, String> {
    let parts: Vec<&str> = line.split_whitespace().collect();
    match parts.as_slice() {
        ["add", name, qty] => Ok(Command::Add(name.to_string(), qty.parse().map_err(|_| "qty ভুল")?)),
        ["sell", name, qty] => Ok(Command::Sell(name.to_string(), qty.parse().map_err(|_| "qty ভুল")?)),
        ["report"] => Ok(Command::Report),
        _ => Err(format!("বুঝিনি: {line}")),
    }
}

fn main() {
    let mut stock: BTreeMap<String, u32> = BTreeMap::new();
    for line in io::stdin().lock().lines() {
        let line = line.expect("পড়া গেল না");
        match parse(&line) {
            Ok(Command::Add(name, qty)) => *stock.entry(name).or_insert(0) += qty,
            Ok(Command::Sell(name, qty)) => match stock.get_mut(&name) {
                Some(have) if *have >= qty => *have -= qty,
                Some(have) => println!("✗ {name}: আছে {have}টা, চাইছেন {qty}টা"),
                None => println!("✗ {name} নামে কিছু নেই"),
            },
            Ok(Command::Report) => {
                for (name, qty) in &stock {
                    println!("  {name:<10} {qty:>3}টা");
                }
            }
            Err(msg) => println!("✗ {msg}"),
        }
    }
}
