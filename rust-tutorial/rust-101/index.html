Rust কেন শিখবেন?

  • দ্রুত: সরাসরি machine code-এ compile হয়, C/C++-এর কাছাকাছি গতি

  • কোথায় চলে: web server, CLI tool, WebAssembly, embedded, এমনকি PHP extension

পাঠ ৫

println! দিয়ে সুন্দর করে প্রিন্ট

{} জায়গায় মান বসে। Variable-এর নাম সরাসরি {name} লেখা যায়।

  • {:.2} — দশমিকের পর ২ ঘর
  • {:>8} — ডানে সাজিয়ে ৮ ঘর জায়গা
  • {:?} — debug আকারে (পরে কাজে লাগবে)
PHP/Laravel-এ যেমন printf("%.2f", $price) বা "Hello {$name}" — Rust-এ সব {} দিয়ে।
Rust
fn main() {
    let name = "Rahim";
    let price = 1250.5;
    let qty = 3;

    println!("Customer: {}", name);
    println!("Customer: {name}");
    println!("Total: {:.2} টাকা", price * qty as f64);
    println!("[{:>8}] [{:<8}]", "ডানে", "বামে");
    println!("{:?}", (name, qty));
}
আউটপুট

let: variable সাধারণত বদলানো যায় না

Rust-এ let দিয়ে variable বানাই। ডিফল্টভাবে এটা immutable — একবার মান দিলে আর বদলানো যায় না।

PHP/Laravel-এ যেমন PHP-তে $x = 5; $x = 6; চলে। Rust-এ বদলাতে চাইলে আগে থেকে বলে দিতে হয়।
💡 Error message-এর শেষে compiler নিজেই সমাধান বলে দিচ্ছে: let mut balance। Rust compiler-এর error পড়তে শিখলে অর্ধেক কাজ শেষ।
Rust
fn main() {
    let balance = 500;
    println!("Balance: {balance}");
    balance = 700;
    println!("Balance: {balance}");
}

পাঠ ৭

mut: বদলানোর অনুমতি

বদলাতে চাইলে let mut লিখুন। এতে কোড পড়েই বোঝা যায় কোন মান বদলাবে আর কোনটা বদলাবে না।

❓ let x = 1; লিখে পরে x += 1; করলে কী হবে?

Compile হবে না (E0384)। let mut x = 1; লিখতে হবে।

Rust
fn main() {
    let mut balance = 500;
    println!("শুরুতে: {balance} টাকা");

    balance = balance + 200;   // bKash থেকে এলো
    balance -= 50;             // রিকশা ভাড়া
    println!("এখন: {balance} টাকা");
}
আউটপুট

এখন: 650 টাকা
পাঠ ৮

Shadowing: একই নামে নতুন variable

একই নামে আবার let লিখলে আগের variable ঢাকা পড়ে যায় (shadow)। এতে type-ও বদলানো যায়।

  • mut একই variable-এর মান বদলায়, type বদলাতে পারে না
  • Shadowing নতুন variable বানায়, তাই type বদলানো যায়
  • ইনপুট পরিষ্কার করতে খুব কাজে লাগে: text → number
Rust
fn main() {
    let phone = "  01711-000000  ";
    let phone = phone.trim();          // একই নাম, নতুন মান
    println!("[{phone}]");

    let qty = "12";                    // এটা text (&str)
    let qty: i32 = qty.parse().unwrap(); // এখন number
    println!("দ্বিগুণ: {}", qty * 2);
}
আউটপুট
[01711-000000]
দ্বিগুণ: 24

const: কখনো না বদলানো মান

const সব সময় immutable, type লিখতেই হবে, আর নাম সাধারণত বড় হাতের অক্ষরে।

PHP/Laravel-এ যেমন Laravel-এর config() বা PHP-র const VAT = 15; এর মতো।
Rust
const VAT_PERCENT: f64 = 15.0;
const SHOP_NAME: &str = "Rahim Mobile";

fn main() {
    let price = 1000.0;
    let vat = price * VAT_PERCENT / 100.0;
    println!("{SHOP_NAME}");
    println!("দাম {price}, VAT {vat}, মোট {}", price + vat);
}

পাঠ ১০

Integer: পূর্ণ সংখ্যা

Rust-এ number-এর আকার আপনি ঠিক করেন। i = চিহ্নসহ (ঋণাত্মক হতে পারে), u = শুধু ধনাত্মক।

Typeসীমাকখন
i32প্রায় ±২১৪ কোটিডিফল্ট, সাধারণ কাজে
i64অনেক বড়টাকার হিসাব (পয়সায়), id
u8০ – ২৫৫বয়স, byte
usizemachine অনুযায়ীindex, length
💡 টাকার হিসাব কখনো float-এ রাখবেন না। পয়সায় (i64) রাখুন: ১২.৫০ টাকা = ১২৫০ পয়সা।
Rust
fn main() {
    let age: u8 = 25;
    let population: i64 = 17_00_00_000;  // _ শুধু পড়ার সুবিধার জন্য
    let temp = -3;                        // ধরে নেয় i32

    println!("বয়স {age}, জনসংখ্যা {population}, তাপমাত্রা {temp}");
    println!("u8 সর্বোচ্চ: {}", u8::MAX);
    println!("i32 সর্বোচ্চ: {}", i32::MAX);
}

পাঠ ১১

Float আর ভাগের ফাঁদ

দশমিক সংখ্যার জন্য f64। দুইটা integer ভাগ করলে ফলও integer হয় — দশমিক বাদ যায়।

  • 7 / 2 = 3 (integer ভাগ)
  • 7.0 / 2.0 = 3.5
  • Type বদলাতে as: 7 as f64
  • % = ভাগশেষ
Rust
fn main() {
    let a = 7;
    let b = 2;
    println!("{} / {} = {}", a, b, a / b);
    println!("ভাগশেষ = {}", a % b);
    println!("দশমিকসহ = {}", a as f64 / b as f64);
    println!("পাই ≈ {:.3}", std::f64::consts::PI);
}

7 / 2 = 3
ভাগশেষ = 1
দশমিকসহ = 3.5
পাই ≈ 3.142

bool আর char

bool হয় true নয়তো false। char একটা অক্ষর, single quote দিয়ে — বাংলা অক্ষরও চলে।

PHP/Laravel-এ যেমন PHP-তে 'অ' একটা string। Rust-এ 'অ' হলো char, আর "অ" হলো string।
Rust
fn main() {
    let is_open = true;
    let has_stock = false;
    println!("দোকান খোলা? {is_open}, স্টক আছে? {has_stock}");
    println!("দুটোই? {}", is_open && has_stock);

    let letter = 'অ';
    let emoji = '📱';
    println!("{letter} {emoji}");
    println!("'অ' এর memory: {} byte", std::mem::size_of::<char>());
}

পাঠ ১৩

String: দুই ধরনের লেখা

আপাতত মনে রাখুন: "Dhaka" লিখলে পাই &str (স্থির লেখা)। বদলানো বা বাড়ানো যায় এমন লেখার জন্য String।

  • String::from("..") বা "..".to_string() দিয়ে String
  • push_str দিয়ে শেষে যোগ
  • format! — println!-এর মতো, কিন্তু String ফেরত দেয়
PHP/Laravel-এ যেমন PHP-তে $a . $b। Rust-এ সবচেয়ে সহজ format!("{a}{b}")।
⚠️ len() অক্ষর না, byte গোনে। বাংলা অক্ষর ৩ byte করে, তাই বাংলায় সংখ্যা বড় দেখাবে। ১০২-এ বিস্তারিত।
Rust
fn main() {
    let city = "Dhaka";                    // &str
    let mut address = String::from("Mirpur 10");
    address.push_str(", ");
    address.push_str(city);
    println!("{address}");

    let line = format!("{} — {} অক্ষর", address, address.len());
    println!("{line}");
}
আউটপুট
Mirpur 10, Dhaka
Mirpur 10, Dhaka — 16 অক্ষর

Tuple: কয়েকটা মান একসাথে

আলাদা type-এর কয়েকটা মান একসাথে রাখতে tuple। .0, .1 দিয়ে নেওয়া যায়, অথবা ভেঙে আলাদা variable-এ।

PHP/Laravel-এ যেমন PHP-র [$name, $price] = ['Redmi', 23500]; এর মতো।
Rust
fn main() {
    let product = ("Redmi Note 13", 23500, true);
    println!("নাম: {}", product.0);
    println!("দাম: {}", product.1);

    let (name, price, in_stock) = product;   // ভেঙে নেওয়া
    println!("{name} — {price} টাকা — স্টকে: {in_stock}");
}

Array: একই type-এর নির্দিষ্ট সংখ্যক মান

Array-এর দৈর্ঘ্য স্থির। দৈর্ঘ্য বাড়াতে-কমাতে হলে Vec লাগে (১০২-এ)।

PHP/Laravel-এ যেমন PHP array একসাথে list আর map। Rust-এ এগুলো আলাদা: array/Vec (list) আর HashMap (key-value)।
Rust
fn main() {
    let days = ["শনি", "রবি", "সোম", "মঙ্গল", "বুধ", "বৃহস্পতি", "শুক্র"];
    let sales = [1200, 3400, 2100];

    println!("প্রথম দিন: {}", days[0]);
    println!("মোট দিন: {}", days.len());
    println!("সব বিক্রি: {:?}", sales);

    let zeros = [0; 5];       // ৫টা শূন্য
    println!("{:?}", zeros);
}

[0, 0, 0, 0, 0]

Array-এর বাইরে গেলে কী হয়?

PHP-তে ভুল index দিলে শুধু warning আর null। Rust সাথে সাথে program থামিয়ে দেয় (panic), ভুল মান নিয়ে চলতে দেয় না।

💡 নিরাপদে নিতে sales.get(5) — এটা panic না করে "নেই" (None) ফেরত দেয়। ১০২-এ Option শিখব।
Rust
fn main() {
    let sales = [1200, 3400, 2100];
    let index = sales.len() + 2;   // ইচ্ছা করে ভুল index
    println!("চেষ্টা করছি index {index}...");
    println!("{}", sales[index]);
}
Program থেমে গেল (panic)
চেষ্টা করছি index 5...
thread 'main' panicked at src/main.rs:5:20:
index out of bounds: the len is 3 but the index is 5

Return: শেষ লাইনই ফলাফল

-> i64 দিয়ে return type বলি। শেষ লাইনে semicolon না দিলে সেটাই ফেরত যায়। আগে ফেরত দিতে return লেখা যায়।

Rust
fn total_price(price: i64, qty: i64) -> i64 {
    price * qty            // ; নেই, তাই এটাই return
}

fn discount(amount: i64) -> i64 {
    if amount < 1000 {
        return 0;          // আগে ফেরত দেওয়া
    }
    amount * 5 / 100
}

fn main() {
    let t = total_price(450, 4);
    println!("মোট {t}, ছাড় {}, দেবেন {}", discount(t), t - discount(t));
}

মোট 1800, ছাড় 90, দেবেন 1710

Block-ও একটা মান

{ } block-এর শেষ লাইন (semicolon ছাড়া) পুরো block-এর মান হয়। তাই block দিয়ে variable-এ মান বসানো যায়।

if একটা মান দেয়

fn main() {

💡 &'static str মানে লেখাটা পুরো program জুড়ে থাকবে। 'static নিয়ে ১০৩-এ বিস্তারিত।

fn grade(marks: u32) -> &'static str {
    if marks >= 80 {
        "A+"
    } else if marks >= 70 {
        "A"
    } else if marks >= 60 {
        "A-"
    } else if marks >= 50 {
        "B"
    } else if marks >= 33 {
        "C/D"
    } else {
        "F"
    }
}

fn main() {
    for m in [95, 72, 48, 20] {
        println!("{m} নম্বর → {}", grade(m));
    }
}

loop: থামতে বলা পর্যন্ত চলে

loop চিরকাল চলে, break দিয়ে থামাতে হয়। break-এর সাথে একটা মানও ফেরত দেওয়া যায়।

Rust
fn main() {
    let mut savings = 1000;
    let mut month = 0;

    let months_needed = loop {
        month += 1;
        savings += savings * 10 / 100;   // মাসে ১০% বাড়ে
        if savings >= 2000 {
            break month;                 // মান সহ বের হলাম
        }
    };
    println!("{months_needed} মাসে দ্বিগুণ, এখন {savings} টাকা");
}

for আর range: নামতা

1..=10 মানে ১ থেকে ১০ (১০ সহ)। 1..10 মানে ১০ বাদ। উল্টো দিকে যেতে .rev()।

PHP/Laravel-এ যেমন for ($i = 1; $i <= 5; $i++) আর foreach ($cities as $city) — Rust-এ দুটোই for ... in।
Rust
fn main() {
    let n = 7;
    for i in 1..=5 {
        println!("{n} × {i} = {}", n * i);
    }

    for i in (1..=3).rev() {
        print!("{i} ");
    }
    println!();

    for city in ["Dhaka", "Khulna", "Barishal"] {
        print!("{city} | ");
    }
    println!();
}

match: PHP 8-এর match-এর বড় ভাই

match একটা মানকে কয়েকটা pattern-এর সাথে মিলিয়ে দেখে। সব সম্ভাবনা ধরতেই হবে — বাকি সবকিছুর জন্য _।

  • 1 | 7 — এটা বা ওটা
  • 2..=6 — range
  • _ — বাকি সব
Rust
fn day_type(day: u8) -> &'static str {
    match day {
        6 => "ছুটি (শুক্রবার)",
        7 => "হাফ ডে (শনিবার)",
        1..=5 => "কাজের দিন",
        _ => "ভুল দিন",
    }
}

fn main() {
    for d in [1, 6, 7, 9] {
        println!("দিন {d}: {}", day_type(d));
    }
}

Keyboard থেকে input

std::io::stdin().read_line() একটা লাইন পড়ে String-এ রাখে। তারপর trim() করে parse() দিয়ে number বানাই।

  • use std::io; — library থেকে io আনলাম (PHP-র use-এর মতো)
  • &mut input — function-কে আমাদের String বদলানোর অনুমতি দিলাম
  • .expect("...") — ভুল হলে এই বার্তা দিয়ে থামবে
PHP/Laravel-এ যেমন PHP CLI-তে $kg = (int) trim(fgets(STDIN));
Rust
use std::io;

fn main() {
    println!("কত কেজি চাল কিনবেন?");
    let mut input = String::new();
    io::stdin().read_line(&mut input).expect("পড়া গেল না");

    let kg: u32 = input.trim().parse().expect("সংখ্যা লিখুন");
    println!("{kg} কেজি × ৭৫ টাকা = {} টাকা", kg * 75);
}

Project: টাকার নোট ভাঙানো

ক্যাশ কাউন্টারে ফেরত দিতে কোন নোট কয়টা লাগবে? Array, for, integer ভাগ আর ভাগশেষ — সব একসাথে।

নিজে করুন শেষে মোট কয়টা নোট লাগল সেটাও প্রিন্ট করুন (একটা let mut total = 0; লাগবে)।
Rust
use std::io;

fn main() {
    let notes = [1000, 500, 200, 100, 50, 20, 10, 5, 2, 1];

    println!("কত টাকা ফেরত দিতে হবে?");
    let mut input = String::new();
    io::stdin().read_line(&mut input).expect("পড়া গেল না");
    let mut amount: u32 = input.trim().parse().expect("সংখ্যা লিখুন");

    for note in notes {
        let count = amount / note;
        if count > 0 {
            println!("{note:>5} টাকার নোট × {count}");
            amount %= note;
        }
    }
}
