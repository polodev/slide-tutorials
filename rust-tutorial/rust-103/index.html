Trait: একটা চুক্তি

Trait বলে দেয় একটা type-এর কী কী method থাকতেই হবে। যে type trait impl করবে, তাকে সব method লিখতে হবে।

PHP/Laravel-এ যেমন interface Payable { public function amount(): int; } আর class Invoice implements Payable — Rust-এ trait আর impl Payable for Invoice।
Rust
trait Payable {
    fn amount(&self) -> u32;
}

struct Invoice { total: u32 }
struct ServiceBill { parts: u32, labour: u32 }

impl Payable for Invoice {
    fn amount(&self) -> u32 { self.total }
}

impl Payable for ServiceBill {
    fn amount(&self) -> u32 { self.parts + self.labour }
}

fn main() {
    let a = Invoice { total: 23500 };
    let b = ServiceBill { parts: 1800, labour: 500 };
    println!("Invoice: {}, Service: {}", a.amount(), b.amount());
}
আউটপুট
Invoice: 23500, Service: 2300

Default method

Trait-এর ভিতরে method-এর ডিফল্ট কোড লেখা যায়। যে type চায়, সে নিজের মতো বদলাতে (override) পারে।

PHP/Laravel-এ যেমন PHP-তে interface-এ কোড থাকে না, তাই trait বা abstract class লাগে। Rust trait দুটো কাজই করে।
Rust
trait Payable {
    fn amount(&self) -> u32;

    fn with_vat(&self) -> u32 {          // ডিফল্ট কোড
        self.amount() * 115 / 100
    }
}

struct Invoice { total: u32 }
struct Donation { total: u32 }

impl Payable for Invoice {
    fn amount(&self) -> u32 { self.total }
}

impl Payable for Donation {
    fn amount(&self) -> u32 { self.total }
    fn with_vat(&self) -> u32 { self.total }   // দানে VAT নেই
}

fn main() {
    println!("{}", Invoice { total: 1000 }.with_vat());
    println!("{}", Donation { total: 1000 }.with_vat());
}

1150
1000

Trait দিয়ে যেকোনো type নেওয়া

impl Payable parameter মানে "Payable হলেই চলবে"। আলাদা type একই list-এ রাখতে Box<dyn Payable>।

Rust
trait Payable {
    fn amount(&self) -> u32;
    fn label(&self) -> String;
}

struct Invoice { no: u32, total: u32 }
struct Expense { name: String, cost: u32 }

impl Payable for Invoice {
    fn amount(&self) -> u32 { self.total }
    fn label(&self) -> String { format!("Invoice #{}", self.no) }
}
impl Payable for Expense {
    fn amount(&self) -> u32 { self.cost }
    fn label(&self) -> String { format!("খরচ: {}", self.name) }
}

fn show(item: &impl Payable) {
    println!("{:<14} {:>6}", item.label(), item.amount());
}

fn main() {
    let items: Vec<Box<dyn Payable>> = vec![
        Box::new(Invoice { no: 101, total: 23500 }),
        Box::new(Expense { name: "ভাড়া".into(), cost: 15000 }),
    ];
    for it in &items {
        println!("{:<14} {:>6}", it.label(), it.amount());
    }
    show(&Invoice { no: 102, total: 900 });
}
আউটপুট
Invoice #101    23500
খরচ: ভাড়া      15000
Invoice #102      900

derive: কাজের trait বিনা খরচে

অনেক সাধারণ trait compiler নিজেই লিখে দেয়। #[derive(...)] লিখলেই হলো।

Traitকী পাবেন

Clone.clone()
PartialEq== দিয়ে তুলনা

Rust
#[derive(Debug, Clone, PartialEq, Default)]
struct Customer {
    name: String,
    due: u32,
}

fn main() {

    let b = a.clone();

Display: নিজের মতো করে {} দিয়ে প্রিন্ট

{} দিয়ে প্রিন্ট করতে std::fmt::Display trait নিজে লিখতে হয়।

PHP/Laravel-এ যেমন PHP-র __toString() magic method-এর মতো।
💡 struct Taka(i64) হলো tuple struct — একটা মানকে নতুন নাম দেওয়া, যাতে ভুল করে পয়সা আর টাকা মিশে না যায়।
Rust
use std::fmt;

struct Taka(i64);   // পয়সায় রাখা টাকা

impl fmt::Display for Taka {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "৳{}.{:02}", self.0 / 100, self.0 % 100)
    }
}

fn main() {
    let price = Taka(2350050);
    println!("দাম: {price}");
    println!("ছাড়: {}", Taka(1999));
}

Generic function

<T> মানে "যেকোনো type"। কিন্তু T নিয়ে কী করা যাবে, সেটা trait bound দিয়ে বলতে হয়: T: PartialOrd মানে তুলনা করা যায়।

PHP/Laravel-এ যেমন PHP-তে type না দিলেই যেকোনো type চলে, কিন্তু ভুল type চলার সময় ধরা পড়ে। Rust generic compile-এর সময়েই নিশ্চিত করে।
Rust
fn largest<T: PartialOrd + Copy>(list: &[T]) -> T {
    let mut big = list[0];
    for &item in list {
        if item > big {
            big = item;
        }
    }
    big
}

fn main() {
    println!("{}", largest(&[1200, 3400, 2100]));
    println!("{}", largest(&[4.5, 3.9, 4.8]));
    println!("{}", largest(&['ক', 'খ', 'গ']));
}

4.8
গ

Generic struct

PHP/Laravel-এ যেমন Laravel-এর paginate() যেকোনো model-এর জন্য একই — এখানে Paginated<T> যেকোনো type-এর জন্য।
Rust
#[derive(Debug)]
struct Paginated<T> {
    items: Vec<T>,
    page: u32,
    total: u32,
}

impl<T> Paginated<T> {
    fn has_next(&self, per_page: u32) -> bool {
        self.page * per_page < self.total
    }
}

fn main() {
    let phones = Paginated { items: vec!["Redmi", "Vivo"], page: 1, total: 5 };
    let prices = Paginated { items: vec![17500, 21000], page: 3, total: 6 };
    println!("{:?} → পরের পাতা? {}", phones.items, phones.has_next(2));
    println!("{:?} → পরের পাতা? {}", prices.items, prices.has_next(2));
}
আউটপুট
["Redmi", "Vivo"] → পরের পাতা? true
[17500, 21000] → পরের পাতা? false

where: লম্বা bound পরিষ্কার করে লেখা

Bound অনেক হলে where ব্লকে লিখলে function-এর প্রথম লাইন পরিষ্কার থাকে।

Rust
use std::fmt::Display;

fn receipt<T, U>(item: T, price: U) -> String
where
    T: Display,
    U: Display + Copy,
{
    format!("{item} ........ {price} টাকা")
}

fn main() {
    println!("{}", receipt("Charger", 650));
    println!("{}", receipt(String::from("Cover"), 250.5));
}

Closure: ছোট নামহীন function

|x| x * 2 হলো closure। এটা চারপাশের variable ব্যবহার (capture) করতে পারে।

PHP/Laravel-এ যেমন PHP 7.4-এর arrow function fn($x) => $x * $rate একদম একই ধারণা — PHP-তেও বাইরের $rate নিজে থেকেই পায়।
Rust
fn main() {
    let vat = 15;
    let with_vat = |amount: u32| amount + amount * vat / 100;   // vat capture করল

    println!("{}", with_vat(1000));
    println!("{}", with_vat(2400));

    let mut count = 0;
    let mut tick = || count += 1;   // বদলালে closure-ও mut
    tick();
    tick();
    println!("ডাকা হলো {count} বার");
}
আউটপুট
1150
2760
ডাকা হলো 2 বার

Iterator: Laravel Collection-এর মতো

.iter() থেকে শুরু করে map, filter জুড়ে শেষে collect() বা sum()। এটা lazy — শেষ ধাপ না ডাকা পর্যন্ত কিছুই চলে না।

💡 Laravel-এ: collect($prices)->filter(...)->map(...)->values()। Rust-এ একই ভাবনা, কিন্তু compile-এর পর সাধারণ loop-এর মতোই দ্রুত।
Rust
fn main() {
    let prices = vec![17500, 650, 21000, 250, 9900];

    let expensive: Vec<u32> = prices.iter()
        .filter(|&&p| p >= 5000)
        .map(|&p| p * 95 / 100)        // ৫% ছাড়
        .collect();

    println!("দামি ফোন (ছাড়সহ): {:?}", expensive);
    println!("মোট: {}", prices.iter().sum::<u32>());
}
আউটপুট
দামি ফোন (ছাড়সহ): [16625, 19950, 9405]
মোট: 49300

Rust
struct Sale { seller: &'static str, model: &'static str, price: u32 }

fn main() {
    let sales = vec![
        Sale { seller: "Karim", model: "Redmi 13", price: 17500 },
        Sale { seller: "Nusrat", model: "Galaxy A15", price: 21000 },
        Sale { seller: "Karim", model: "Charger", price: 650 },
        Sale { seller: "Rahim", model: "Vivo Y28", price: 18000 },
    ];

    let karim: u32 = sales.iter().filter(|s| s.seller == "Karim").map(|s| s.price).sum();
    let top = sales.iter().max_by_key(|s| s.price).unwrap();
    let cheap = sales.iter().find(|s| s.price < 1000);
    let models: Vec<&str> = sales.iter().map(|s| s.model).collect();

    println!("Karim-এর বিক্রি: {karim}");
    println!("সবচেয়ে দামি: {} ({})", top.model, top.price);
    println!("১০০০-এর কম: {:?}", cheap.map(|s| s.model));
    println!("সব model: {}", models.join(", "));
}

enumerate, zip আর sort

  • zip — দুই list জোড়া লাগায়
  • enumerate — সাথে index দেয় (০ থেকে)
  • sort_by — নিজের তুলনা; b.cmp(a) মানে উল্টো ক্রম
Rust
fn main() {
    let names = ["Karim", "Nusrat", "Rahim"];
    let sales = [52000, 87000, 61000];

    let mut board: Vec<(&str, u32)> = names.iter().copied().zip(sales).collect();
    board.sort_by(|a, b| b.1.cmp(&a.1));      // বেশি থেকে কম

    for (i, (name, amount)) in board.iter().enumerate() {
        println!("{}. {name:<7} {amount:>6}", i + 1);
    }
}

'a দিয়ে সম্পর্ক বলে দেওয়া

'a একটা নাম মাত্র। এর মানে: "ফেরত দেওয়া reference ততক্ষণ ঠিক থাকবে, যতক্ষণ a আর b দুটোই ঠিক থাকে"। এটা memory বদলায় না, শুধু compiler-কে সম্পর্কটা জানায়।

Box: heap-এ রাখা

Box<T> মানটা heap-এ রাখে। দরকার হয় যখন আকার compile-এর সময় জানা নেই — যেমন নিজের ভিতরে নিজেকে রাখা (tree)।

Rust
enum Category {
    Leaf(&'static str),
    Group(&'static str, Vec<Box<Category>>),
}

fn count(c: &Category, depth: usize) -> usize {
    match c {
        Category::Leaf(name) => {
            println!("{}- {name}", "  ".repeat(depth));
            1
        }
        Category::Group(name, kids) => {
            println!("{}+ {name}", "  ".repeat(depth));
            kids.iter().map(|k| count(k, depth + 1)).sum()
        }
    }
}

fn main() {
    let tree = Category::Group("Mobile", vec![
        Box::new(Category::Leaf("Smartphone")),
        Box::new(Category::Group("Accessories", vec![
            Box::new(Category::Leaf("Charger")),
            Box::new(Category::Leaf("Cover")),
        ])),
    ]);
    println!("মোট পাতা-category: {}", count(&tree, 0));
}
আউটপুট
+ Mobile
  - Smartphone
  + Accessories
    - Charger
    - Cover
মোট পাতা-category: 3

Rc: একাধিক মালিক

Ownership-এ মালিক একজন। কিন্তু কখনো কয়েকজনকে একই data-র মালিক হতে হয় — তখন Rc (reference counted)। শেষ মালিক চলে গেলে data drop হয়।

PHP/Laravel-এ যেমন PHP-তে সব object এভাবেই চলে (refcount)। Rust-এ এটা আপনি নিজে বেছে নেন, তাই খরচটা চোখে পড়ে।
Rust
use std::rc::Rc;

struct Shop { name: String }

fn main() {
    let shop = Rc::new(Shop { name: "Rahim Mobile".into() });
    let for_pos = Rc::clone(&shop);      // কপি না, শুধু গণনা বাড়ল
    let for_report = Rc::clone(&shop);

    println!("{} — মালিক {} জন", for_pos.name, Rc::strong_count(&shop));
    drop(for_report);
    println!("একজন গেল — মালিক {} জন", Rc::strong_count(&shop));
}
আউটপুট
Rahim Mobile — মালিক 3 জন
একজন গেল — মালিক 2 জন
পাঠ ১৭

RefCell: ধার নিয়মের হিসাব চলার সময়

Rc-এর ভিতরের মান বদলানো যায় না। বদলাতে Rc<RefCell<T>>। নিয়ম ভাঙলে compile error না, চলার সময় panic।

⚠️ RefCell সহজ মনে হলেও আগে সাধারণ &mut দিয়ে চেষ্টা করুন। Web server-এ thread-এর মধ্যে ভাগ করতে Arc<Mutex> লাগবে (এই কোর্সেই সামনে)।
Rust
use std::cell::RefCell;
use std::rc::Rc;

fn main() {
    let cart = Rc::new(RefCell::new(Vec::<&str>::new()));
    let pos = Rc::clone(&cart);
    let app = Rc::clone(&cart);

    pos.borrow_mut().push("Charger");
    app.borrow_mut().push("Cover");
    println!("Cart: {:?}", cart.borrow());
}
আউটপুট
Cart: ["Charger", "Cover"]

Test লেখা

Function-এর উপরে #[test], ভিতরে assert_eq!। cargo test সব test চালায় — আলাদা package লাগে না।

PHP/Laravel-এ যেমন PHPUnit/Pest-এর expect($x)->toBe(5) এর মতো। Rust-এ test সাধারণত একই file-এর নিচে mod tests-এ থাকে।
Rust
fn vat(amount: u32) -> u32 {
    amount * 15 / 100
}

fn discount(amount: u32) -> u32 {
    if amount >= 10_000 { amount / 10 } else { 0 }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn vat_is_15_percent() {
        assert_eq!(vat(1000), 150);
    }

    #[test]
    fn no_discount_below_10k() {
        assert_eq!(discount(9_999), 0);
    }

    #[test]
    fn ten_percent_from_10k() {
        assert_eq!(discount(20_000), 2_000);
    }
}

JSON থেকে struct

Deserialize করলে JSON পড়ে struct বানায়। কোনো field না মিললে বা type ভুল হলে Err দেয় — ভুল data ভিতরে ঢোকে না।

💡 Laravel-এ $request->validate() যে কাজ করে, Rust web-এ অনেকটা সেটাই হয় শুধু type দিয়ে।
Rust
use serde::Deserialize;

#[derive(Deserialize)]
struct Order {
    customer: String,
    items: Vec<String>,
    paid: bool,
}

fn main() {
    let good = r#"{"customer":"Nusrat","items":["Charger","Cover"],"paid":true}"#;
    let bad = r#"{"customer":"Karim","items":"Charger","paid":true}"#;

    let order: Order = serde_json::from_str(good).unwrap();
    println!("{} — {} আইটেম — paid: {}", order.customer, order.items.len(), order.paid);

    match serde_json::from_str::<Order>(bad) {
        Ok(o) => println!("{}", o.customer),
        Err(e) => println!("ভুল JSON: {e}"),
    }
}

Thread: একসাথে কয়েকটা কাজ

thread::spawn নতুন thread চালায়। join() দিয়ে শেষ হওয়া পর্যন্ত অপেক্ষা করি। move দিয়ে data thread-এ পাঠাই।

PHP/Laravel-এ যেমন সাধারণ PHP একটা request-এ একটা কাজ করে। একসাথে কাজ চালাতে Laravel queue বা আলাদা process লাগে। Rust এক program-এর ভিতরেই নিরাপদে পারে।
Rust
use std::thread;

fn main() {
    let branches = vec!["Mirpur", "Uttara", "Gulshan"];
    let mut handles = Vec::new();

    for (i, branch) in branches.into_iter().enumerate() {
        handles.push(thread::spawn(move || {
            let total = (i as u32 + 1) * 10_000;   // ধরি হিসাব করতে সময় লাগে
            (branch, total)
        }));
    }

    for h in handles {
        let (branch, total) = h.join().unwrap();
        println!("{branch}: {total}");
    }
}

Channel: thread থেকে বার্তা পাঠানো

mpsc::channel() একটা পাইপ: অনেকে পাঠাতে (tx) পারে, একজন নেয় (rx)।

⚠️ Thread কোনটা আগে শেষ করবে তার ঠিক নেই — "পেলাম" লাইনের ক্রম প্রতিবার বদলাতে পারে, কিন্তু মোট সবসময় একই।
Rust
use std::sync::mpsc;
use std::thread;

fn main() {
    let (tx, rx) = mpsc::channel();

    for branch in ["Mirpur", "Uttara", "Gulshan"] {
        let tx = tx.clone();
        thread::spawn(move || {
            let sale = branch.len() as u32 * 1000;
            tx.send((branch, sale)).unwrap();
        });
    }
    drop(tx);   // মূল tx বন্ধ, নইলে rx চিরকাল অপেক্ষা করবে

    let mut total = 0;
    for (branch, sale) in rx {
        total += sale;
        println!("পেলাম {branch}");
    }
    println!("সব শাখা মিলে: {total}");
}

Arc + Mutex: ভাগ করা data নিরাপদে বদলানো

অনেক thread একটা মান বদলাতে চাইলে: Arc (thread-safe Rc) দিয়ে ভাগ, Mutex দিয়ে একবারে একজন। Web server-এর shared state ঠিক এভাবেই।

❓ Mutex ছাড়া শুধু Arc<i32> দিয়ে বদলাতে চাইলে কী হবে?

Compile হবে না। Rust data race-কে compile error বানায় — এটাই "fearless concurrency"।

Rust
use std::sync::{Arc, Mutex};
use std::thread;

fn main() {
    let stock = Arc::new(Mutex::new(100));
    let mut handles = vec![];

    for _ in 0..10 {
        let stock = Arc::clone(&stock);
        handles.push(thread::spawn(move || {
            let mut s = stock.lock().unwrap();   // তালা দিলাম
            *s -= 3;                              // ৩টা বিক্রি
        }));                                      // scope শেষে তালা খুলল
    }
    for h in handles {
        h.join().unwrap();
    }
    println!("বাকি স্টক: {}", stock.lock().unwrap());
}

async/await: অপেক্ষার সময় অন্য কাজ

Network বা database-এর জন্য অপেক্ষায় thread বসিয়ে রাখা অপচয়। async function অপেক্ষার সময় অন্য কাজ চালাতে দেয়। চালাতে runtime লাগে — সবচেয়ে জনপ্রিয় tokio।

PHP/Laravel-এ যেমন PHP request সাধারণত একটার পর একটা অপেক্ষা করে। Rust web framework (axum) পুরোটাই async — হাজার request একসাথে অল্প thread-এ।
Rust
use std::time::Duration;
use tokio::time::sleep;

async fn fetch_price(model: &str, ms: u64) -> (String, u32) {
    sleep(Duration::from_millis(ms)).await;   // ধরি API call
    (model.to_string(), ms as u32 * 100)
}

#[tokio::main]
async fn main() {
    let start = std::time::Instant::now();
    let (a, b) = tokio::join!(fetch_price("Redmi 13", 200), fetch_price("Galaxy A15", 300));
    println!("{a:?}\n{b:?}");
    println!("সময় লাগল ~{} ms (২০০ + ৩০০ না!)", start.elapsed().as_millis() / 100 * 100);
}

Project: বিক্রির CSV থেকে রিপোর্ট

CSV লাইন পড়া, ভুল লাইন বাদ দেওয়া, শাখা ধরে যোগফল আর সেরা model — struct, Result, iterator আর BTreeMap একসাথে।

নিজে করুন রিপোর্টের জন্য একটা #[test] লিখুন: ভুল দামের লাইন Err দেয় কিনা।
Rust
use std::collections::BTreeMap;

#[derive(Debug)]
struct Sale { branch: String, model: String, price: u32 }

fn parse(line: &str) -> Result<Sale, String> {
    let f: Vec<&str> = line.split(',').map(|x| x.trim()).collect();
    let [branch, model, price] = f.as_slice() else {
        return Err(format!("৩টা ঘর নেই: {line}"));
    };
    let price = price.parse().map_err(|_| format!("দাম ভুল: {line}"))?;
    Ok(Sale { branch: branch.to_string(), model: model.to_string(), price })
}

fn main() {
    let csv = "Mirpur, Redmi 13, 17500
Uttara, Galaxy A15, 21000
Mirpur, Charger, 650
Uttara, Vivo Y28, 18OOO
Gulshan, iPhone 15
Gulshan, Galaxy A15, 21000";

    let (ok, bad): (Vec<_>, Vec<_>) = csv.lines().map(parse).partition(|r| r.is_ok());
    let sales: Vec<Sale> = ok.into_iter().map(Result::unwrap).collect();

    let mut by_branch: BTreeMap<&str, u32> = BTreeMap::new();
    for s in &sales {
        *by_branch.entry(&s.branch).or_insert(0) += s.price;
    }
    for (b, total) in &by_branch {
        println!("{b:<8} {total:>6}");
    }
    let best = sales.iter().max_by_key(|s| s.price).unwrap();
    println!("সবচেয়ে দামি বিক্রি: {} ({})", best.model, best.branch);
    for e in bad {
        println!("বাদ: {}", e.unwrap_err());
    }
}
