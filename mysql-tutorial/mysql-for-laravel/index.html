Eloquent-এর ভিতরে

এই কোর্সের প্রতিটি Laravel কোড আসলেই চালানো হয়েছে, আর পাশে দেখানো হয়েছে MySQL-এ ঠিক কোন query গেল আর কয়টা। Debugbar যা দেখায়, সেটা বুঝতে শিখব।

  • toRawSql() আর query log
  • where/orWhere-এর ফাঁদ
  • whereHas, withCount-এর SQL
  • N+1 আর with()
  • create বনাম insert, increment-এর atomic UPDATE
  • Transaction আর lockForUpdate
  • paginate, simplePaginate, cursorPaginate
  • Migration কোন SQL বানায়; টাকা, soft delete, index

আগে জানা দরকার: MySQL 102 (JOIN, GROUP BY) আর Laravel-এর Eloquent-এর সাধারণ ব্যবহার।

Database আর Model

MySQL 102-এর দোকানের database। Model-গুলো সাধারণ Laravel model — relationship সহ।

💡 এখানে Laravel-এর database অংশ (illuminate/database) আলাদাভাবে চালানো হয়েছে — একই Eloquent, একই SQL।
MySQL — schema + seed (MySQL 102 থেকে)
CREATE TABLE branches (
    id   INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(50) NOT NULL
);

CREATE TABLE customers (
    id       INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    name     VARCHAR(100) NOT NULL,
    phone    VARCHAR(15)  NOT NULL UNIQUE,
    district VARCHAR(50)
);

CREATE TABLE categories (
    id   INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(50) NOT NULL
);

CREATE TABLE products (
    id          INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    category_id INT UNSIGNED NOT NULL,
    name        VARCHAR(100) NOT NULL,
    brand       VARCHAR(50)  NOT NULL,
    cost        DECIMAL(10,2) NOT NULL,
    price       DECIMAL(10,2) NOT NULL,
    stock       INT UNSIGNED NOT NULL DEFAULT 0,
    FOREIGN KEY (category_id) REFERENCES categories (id)
);

CREATE TABLE employees (
    id        INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    branch_id INT UNSIGNED NOT NULL,
    name      VARCHAR(100) NOT NULL,
    FOREIGN KEY (branch_id) REFERENCES branches (id)
);

CREATE TABLE sales (
    id          INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    invoice_no  VARCHAR(20) NOT NULL UNIQUE,
    branch_id   INT UNSIGNED NOT NULL,
    employee_id INT UNSIGNED NOT NULL,
    customer_id INT UNSIGNED NULL,            -- walk-in হলে NULL
    sold_at     DATETIME NOT NULL,
    total       DECIMAL(10,2) NOT NULL,
    FOREIGN KEY (branch_id)   REFERENCES branches (id),
    FOREIGN KEY (employee_id) REFERENCES employees (id),
    FOREIGN KEY (customer_id) REFERENCES customers (id)
);

CREATE TABLE sale_items (
    id         INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    sale_id    INT UNSIGNED NOT NULL,
    product_id INT UNSIGNED NOT NULL,
    qty        INT UNSIGNED NOT NULL,
    unit_price DECIMAL(10,2) NOT NULL,
    FOREIGN KEY (sale_id)    REFERENCES sales (id) ON DELETE CASCADE,
    FOREIGN KEY (product_id) REFERENCES products (id)
);

পাঠ ২

Eloquent কোন SQL বানাল? toRawSql()

->toRawSql() query না চালিয়ে SQL দেখায় (মান বসিয়ে)। ->toSql() দেখায় ? সহ। Debug করার প্রথম ধাপ।

💡 queries(fn () => ...) হলো এই কোর্সের ছোট helper: ভিতরে যত query চলে, সব নম্বরসহ দেখায় — Debugbar-এর মতো। Laravel app-এ একই কাজ DB::listen() বা DB::enableQueryLog()।
Laravel
echo Product::where('brand', 'Xiaomi')
    ->where('price', '<', 20000)
    ->orderByDesc('price')
    ->toRawSql();
Laravel চালিয়ে পাওয়া আউটপুট
select * from `products` where `brand` = 'Xiaomi' and `price` < 20000 order by `price` desc
পাঠ ৩

orWhere-এর ফাঁদ

"Xiaomi অথবা Samsung, যাদের স্টক আছে" — সরল লিখলে SQL-এ AND আগে বাঁধে, ফল ভুল।

⚠️ প্রথমটায় Redmi Note 13 (স্টক ২) চলে এসেছে। orWhere থাকলে সবসময় closure দিয়ে bracket করুন।
Laravel
$wrong = Product::where('brand', 'Xiaomi')->orWhere('brand', 'Samsung')->where('stock', '>', 2);
echo $wrong->toRawSql(), "\n", $wrong->pluck('name')->join(', '), "\n\n";

$right = Product::where(fn ($q) => $q->where('brand', 'Xiaomi')->orWhere('brand', 'Samsung'))
    ->where('stock', '>', 2);
echo $right->toRawSql(), "\n", $right->pluck('name')->join(', ');
Laravel চালিয়ে পাওয়া আউটপুট
select * from `products` where `brand` = 'Xiaomi' or `brand` = 'Samsung' and `stock` > 2
Redmi 13, Redmi Note 13, Galaxy A15

select * from `products` where (`brand` = 'Xiaomi' or `brand` = 'Samsung') and `stock` > 2
Redmi 13, Galaxy A15
পাঠ ৪

whereHas = EXISTS subquery

whereHas প্রতিটি customer-এর জন্য EXISTS subquery চালায়। বড় table-এ sales.customer_id-এ index থাকা জরুরি (foreign key দিলে MySQL নিজেই বানায়)।

Laravel
$q = Customer::whereHas('sales', fn ($s) => $s->where('total', '>', 20000));
echo $q->toRawSql(), "\n\n";
echo $q->pluck('name')->join(', ');
Laravel চালিয়ে পাওয়া আউটপুট
select * from `customers` where exists (select * from `sales` where `customers`.`id` = `sales`.`customer_id` and `total` > 20000)

Nusrat Jahan, Rahim Mia, Sadia Islam, Tanvir Hasan
পাঠ ৫

withCount আর withSum

সম্পর্কিত row গোনা বা যোগ করা — আলাদা query না, একই SELECT-এর ভিতরে subquery।

Laravel
$customers = queries(fn () => Customer::withCount('sales')
    ->withSum('sales', 'total')
    ->orderByDesc('sales_sum_total')
    ->limit(3)
    ->get());

foreach ($customers as $c) {
    echo "{$c->name}: {$c->sales_count}টা, {$c->sales_sum_total} টাকা\n";
}

GROUP BY: selectRaw দিয়ে

⚠️ selectRaw-এ কখনো user input সরাসরি জুড়বেন না। মান লাগলে দ্বিতীয় parameter-এ binding দিন: selectRaw('price * ? AS with_vat', [1.15])।
Laravel
$rows = Sale::query()
    ->join('branches', 'branches.id', '=', 'sales.branch_id')
    ->selectRaw('branches.name AS branch, COUNT(*) AS invoices, SUM(total) AS revenue')
    ->groupBy('branches.id', 'branches.name')
    ->orderByDesc('revenue')
    ->get();

foreach ($rows as $r) {
    echo str_pad($r->branch, 8), " {$r->invoices}  {$r->revenue}\n";
}

শুধু যা দরকার: pluck, value, exists

💡 শুধু আছে কিনা জানতে ->first() বা ->get()->count() না — exists() আর count() database-এই হিসাব করে।
Laravel
queries(function () {
    $names  = Product::where('brand', 'Xiaomi')->pluck('name');   // শুধু name column

    $exists = Customer::where('phone', '01711000001')->exists();  // SELECT EXISTS
    $count  = Sale::whereNull('customer_id')->count();
    echo "{$names->join(', ')} | {$price} | " . ($exists ? 'yes' : 'no') . " | walk-in: {$count}\n";
});

N+1: চুপচাপ ৮টা query

প্রতিটি sale-এর customer-এর নাম দেখাতে loop — দেখতে নিরীহ, কিন্তু প্রতিটি $sale->customer একটা নতুন query।

⚠️ ১০টা sale-এ ৮টা query: ১টা sale-এর, আর customer আছে এমন ৭টার প্রতিটির জন্য একটা (walk-in-এ customer_id NULL, তাই query হয়নি — একই customer দুইবার এলেও দুইবার query!)। ১০০০টা sale-এ প্রায় ১০০১টা।

queries(function () {
    foreach (Sale::all() as $sale) {
        $sale->customer?->name;

preventLazyLoading: N+1 হলেই ধরা

AppServiceProvider::boot()-এ এক লাইন দিলে development-এ lazy loading হলেই exception — N+1 production-এ যাওয়ার আগেই ধরা পড়ে।

Laravel
Illuminate\Database\Eloquent\Model::preventLazyLoading();

try {
    foreach (Sale::limit(2)->get() as $sale) {
        echo $sale->customer->name;
    }
} catch (Illuminate\Database\LazyLoadingViolationException $e) {
    echo get_class($e), ":\n", $e->getMessage();
}

create বনাম insert

create() প্রতিটি row-এর জন্য একটা query (event, timestamp, cast সব চলে)। insert() এক query-তে সব, কিন্তু Eloquent-এর কোনো সুবিধা নেই।

💡 হাজার row import-এ insert() (বা chunk করে insert); সাধারণ form save-এ create()।
Laravel
queries(function () {
    foreach (['Jamal' => '01700000101', 'Kamal' => '01700000102'] as $name => $phone) {
        Customer::create(['name' => $name, 'phone' => $phone]);
    }
    Customer::insert([
        ['name' => 'Rina', 'phone' => '01700000103'],
        ['name' => 'Mina', 'phone' => '01700000104'],
    ]);
});

Loop-এ save বনাম এক UPDATE

সব row-এ একই নিয়ম হলে query builder-এর update() — এক query। (তবে এতে model event চলে না।)

Laravel
queries(function () {
    foreach (Product::where('brand', 'Walton')->get() as $p) {   // ১ SELECT + প্রতিটিতে UPDATE
        $p->price = $p->price + 50;
        $p->save();
    }
    Product::where('brand', 'Nokia')->update(['price' => DB::raw('price + 50')]);   // ১ UPDATE
});

$p = Product::find(8);

upsert: থাকলে update, না থাকলে insert

Supplier-এর price list import: product নাম মিললে দাম বদলাও, নইলে নতুন যোগ করো — এক query-তে। MySQL-এ এটা INSERT ... ON DUPLICATE KEY UPDATE, তাই unique key লাগে।

MySQL

queries(fn () => Product::upsert([
    ['category_id' => 1, 'name' => 'Redmi 13',  'brand' => 'Xiaomi', 'cost' => 15500, 'price' => 17200, 'stock' => 5],
    ['category_id' => 1, 'name' => 'Redmi 14C', 'brand' => 'Xiaomi', 'cost' => 13000, 'price' => 14500, 'stock' => 6],
], uniqueBy: ['name'], update: ['cost', 'price']));

echo Product::where('name', 'like', 'Redmi 1%')->get(['name', 'price'])->toJson();

Transaction আর lockForUpdate

Query log-এ for update দেখুন। Closure-এর ভিতরে exception হলে Laravel নিজেই ROLLBACK করে।

💡 Transaction log-এ START TRANSACTION/COMMIT দেখায় না, কারণ Laravel সেগুলো PDO-র method দিয়ে চালায় — কিন্তু database-এ ঠিকই হয়।
Laravel
queries(function () {
    DB::transaction(function () {
        $p = Product::lockForUpdate()->find(4);          // SELECT ... FOR UPDATE
        if ($p->stock < 1) {
            throw new RuntimeException('স্টক নেই');
        }
        $p->decrement('stock');
        $saleId = DB::table('sales')->insertGetId([
            'invoice_no' => 'INV-1012', 'branch_id' => 3, 'employee_id' => 4,
            'sold_at' => '2026-10-20 15:00:00', 'total' => 48000,
        ]);
        DB::table('sale_items')->insert(['sale_id' => $saleId, 'product_id' => 4, 'qty' => 1, 'unit_price' => 48000]);
    });
});

chunk আর lazy: memory বাঁচানো

বড় OFFSET কেন ধীর

LIMIT 20 OFFSET 200000 মানে MySQL ২ লাখ row পড়ে ফেলে দেয়, তারপর ২০টা দেয়। Cursor (keyset) pagination সরাসরি index দিয়ে শুরু জায়গায় যায়।

💡 প্রথমটায় index থেকে ৯টা row পড়ে ৬টা ফেলে দেয়; দ্বিতীয়টা সরাসরি id > 6 থেকে শুরু। ১০ row-এ পার্থক্য নেই, ১০ লাখে বিশাল।
MySQL
EXPLAIN FORMAT=TREE
SELECT id, invoice_no FROM sales ORDER BY id LIMIT 3 OFFSET 6;
ফলাফল
-> Limit/Offset: 3/6 row(s)  (cost=0.941 rows=3)
    -> Index scan on sales using PRIMARY  (cost=0.941 rows=9)
MySQL
EXPLAIN FORMAT=TREE
SELECT id, invoice_no FROM sales WHERE id > 6 ORDER BY id LIMIT 3;
ফলাফল
-> Limit: 3 row(s)  (cost=1.26 rows=3)
    -> Filter: (sales.id > 6)  (cost=1.26 rows=5)
        -> Index range scan on sales using PRIMARY over (6 < id)  (cost=1.26 rows=5)

Migration আসলে কোন SQL

pretend() দিয়ে migration না চালিয়ে শুধু SQL দেখা যায় — php artisan migrate --pretend এটাই করে।

  • id() = bigint unsigned auto_increment primary key
  • foreignId()->constrained() = column + foreign key
  • softDeletes() = nullable deleted_at
Laravel migration → SQL
use Illuminate\Database\Schema\Blueprint;

$queries = DB::connection()->pretend(function () {
    DB::schema()->create('expenses', function (Blueprint $table) {
        $table->id();
        $table->foreignId('branch_id')->constrained()->cascadeOnDelete();
        $table->string('title');
        $table->decimal('amount', 12, 2);
        $table->timestamps();
        $table->softDeletes();
        $table->index(['branch_id', 'created_at']);
    });
});
foreach ($queries as $q) {
    echo $q['query'], ";\n";
}
Laravel চালিয়ে পাওয়া আউটপুট
create table `expenses` (`id` bigint unsigned not null auto_increment primary key, `branch_id` bigint unsigned not null, `title` varchar(255) not null, `amount` decimal(12, 2) not null, `created_at` timestamp null, `updated_at` timestamp null, `deleted_at` timestamp null) default character set utf8mb4 collate 'utf8mb4_0900_ai_ci';
alter table `expenses` add constraint `expenses_branch_id_foreign` foreign key (`branch_id`) references `branches` (`id`) on delete cascade;

DB::raw-এর বিপদ

DB::raw() আর whereRaw()-এ লেখা SQL যেমন আছে তেমনই যায়। User input জুড়লে SQL injection।

💡 নিয়ম: raw SQL-এ মান সবসময় ? আর binding array দিয়ে। Column বা ক্রমের নাম user থেকে নিলে whitelist করুন।
Laravel
$search = "x' OR '1'='1";

$unsafe = Product::whereRaw("name = '$search'");
echo "ভুল: ", $unsafe->count(), " row — সব product বেরিয়ে গেল!\n";

$safe = Product::whereRaw('name = ?', [$search]);
echo "ঠিক: ", $safe->count(), " row\n";
Laravel চালিয়ে পাওয়া আউটপুট

ঠিক: 0 row
