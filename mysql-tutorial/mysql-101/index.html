প্রথম query

SQL-এ SELECT মানে "দেখাও"। Table ছাড়াও হিসাব করা যায়। প্রতিটি statement-এর শেষে ;।

  • AS দিয়ে column-এর নাম দেওয়া যায়
  • SQL keyword ছোট-বড় হাতের যেকোনো অক্ষরে লেখা যায়; বড় হাতের অক্ষরে লেখা প্রচলিত
PHP/Laravel-এ যেমন Laravel-এ DB::select('SELECT 2 + 3 AS total') দিয়ে সরাসরি SQL চালানো যায়।
MySQL
SELECT 2 + 3 AS total, NOW() > '2020-01-01' AS is_after_2020, 'Assalamu Alaikum' AS greeting;

Database বানানো

একটা app-এর সব table একটা database-এ থাকে। বাংলা লেখার জন্য character set অবশ্যই utf8mb4।

PHP/Laravel-এ যেমন Laravel-এর .env-এ DB_DATABASE=shop — database আগে নিজে বানিয়ে নিতে হয়, তারপর php artisan migrate।
⚠️ পুরনো utf8 (utf8mb3) emoji রাখতে পারে না। সবসময় utf8mb4 — Laravel-এর ডিফল্টও এটাই।
Terminal
mysql> CREATE DATABASE shop CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
mysql> SHOW DATABASES;
mysql> USE shop;

CREATE TABLE: প্রথম table

প্রতিটি column-এর নাম আর type বলতে হয়। id হলো PRIMARY KEY — প্রতিটি row-এর আলাদা পরিচয়, AUTO_INCREMENT নিজেই ১, ২, ৩ বসায়।

MySQL
CREATE TABLE customers (
    id         INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    name       VARCHAR(100) NOT NULL,
    phone      VARCHAR(15)  NOT NULL,
    district   VARCHAR(50),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
ফলাফল
Query OK, 0 rows affected
Laravel migration-এ
Schema::create('customers', function (Blueprint $table) {
    $table->id();
    $table->string('name', 100);
    $table->string('phone', 15);
    $table->string('district', 50)->nullable();
    $table->timestamps();
});

products table

এই table-টা পুরো কোর্সে ব্যবহার করব। দামের জন্য DECIMAL, অবস্থার জন্য ENUM।

MySQL
CREATE TABLE products (
    id        INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
    name      VARCHAR(100) NOT NULL,
    brand     VARCHAR(50)  NOT NULL,
    price     DECIMAL(10,2) NOT NULL,
    stock     INT UNSIGNED NOT NULL DEFAULT 0,
    condition_type ENUM('new', 'used') NOT NULL DEFAULT 'new'
);

ORDER BY আর LIMIT

ORDER BY দিয়ে সাজাই (ASC ছোট→বড়, DESC বড়→ছোট)। LIMIT কয়টা দেখাবে, OFFSET কয়টা বাদ দিয়ে শুরু।

MySQL
SELECT name, price FROM products ORDER BY price DESC LIMIT 3;
ফলাফল
+---------------+----------+
| name          | price    |
+---------------+----------+
| iPhone 12     | 48000.00 |
| Galaxy S21    | 32000.00 |
| Redmi Note 13 | 23500.00 |
+---------------+----------+
3 rows in set
MySQL
SELECT name, price FROM products ORDER BY price DESC LIMIT 3 OFFSET 3;   -- দ্বিতীয় পাতা
ফলাফল
+------------+----------+
| name       | price    |
+------------+----------+
| Galaxy A15 | 21000.00 |
| Vivo Y28   | 18000.00 |
| Redmi 13   | 17500.00 |
+------------+----------+
3 rows in set
Laravel-এ
Product::orderByDesc('price')->limit(3)->get();
Product::orderByDesc('price')->paginate(3);   // LIMIT/OFFSET নিজেই করে

হিসাব করা column

SELECT-এ সরাসরি হিসাব করা যায়। নতুন column-এর নাম দিই AS দিয়ে।

MySQL
SELECT name,
       price,
       stock,
       price * stock               AS stock_value,
       ROUND(price * 1.15, 2)      AS price_with_vat,
       CONCAT(brand, ' — ', name)  AS label
FROM products
WHERE stock > 0
ORDER BY stock_value DESC;

CASE: শর্ত অনুযায়ী মান

CASE WHEN ... THEN ... ELSE ... END — SQL-এর if/else।

PHP/Laravel-এ যেমন PHP-র match(true) { $stock === 0 => 'শেষ', ... } এর মতো।
MySQL
SELECT name, stock,
       CASE
           WHEN stock = 0 THEN 'শেষ'
           WHEN stock <= 2 THEN 'কম'
           ELSE 'আছে'
       END AS stock_status
FROM products
ORDER BY stock;

| iPhone 12      |     2 | কম           |
| Vivo Y28       |     4 | আছে          |
| Redmi 13       |     5 | আছে          |
| Walton NEXG N9 |     7 | আছে          |
| Charger 20W    |    30 | আছে          |
+----------------+-------+--------------+

সাবধান: WHERE ছাড়া UPDATE

WHERE ভুলে গেলে সব row বদলে যায়। আগে একই WHERE দিয়ে SELECT চালিয়ে দেখে নিন কোন row বদলাবে।

💡 mysql --safe-updates (বা SET SQL_SAFE_UPDATES = 1;) চালু রাখলে key-ভিত্তিক WHERE ছাড়া UPDATE/DELETE MySQL নিজেই আটকে দেয়।
⚠️ Production database-এ হাতে UPDATE চালানোর আগে backup নিন অথবা transaction-এর ভিতরে চালান (MySQL 103)।
Terminal
mysql> UPDATE products SET price = 0;
Query OK, 8 rows affected   ← সব product-এর দাম ০ হয়ে গেল!

MySQL
SELECT CONCAT(brand, ' ', name) AS phone,
       price,
       stock
FROM products
WHERE condition_type = 'new'
  AND stock > 0
  AND price < 20000
  AND name NOT LIKE 'Charger%'
ORDER BY price;
