Container আর decoration

Container-এ রং, গোল কোণা, border, ছায়া — CSS box-এর মতো। Expanded বাকি জায়গা নিয়ে নেয়।

💡 বারবার লাগে এমন অংশ ছোট function বা নিজের widget বানিয়ে আলাদা করুন — Blade-এর component-এর মতো।
lib/main.dart
import 'package:flutter/material.dart';

void main() => runApp(const App());

class App extends StatelessWidget {
  const App({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.green),
      home: Scaffold(
        appBar: AppBar(title: const Text('Dashboard')),
        body: Padding(
          padding: const EdgeInsets.all(16),
          child: Row(
            children: [
              Expanded(child: _stat('আজ', '৳১,৭০,৪০০', Colors.green)),
              const SizedBox(width: 12),
              Expanded(child: _stat('বাকি', '৳১২,৫০০', Colors.orange)),
            ],
          ),
        ),
      ),
    );
  }

  Widget _stat(String label, String value, Color color) {
    return Container(
      padding: const EdgeInsets.all(16),
      decoration: BoxDecoration(
        color: color.withValues(alpha: 0.12),
        borderRadius: BorderRadius.circular(16),
        border: Border.all(color: color, width: 1.5),
      ),
      child: Column(
        mainAxisSize: MainAxisSize.min,
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Text(label, style: TextStyle(color: color, fontWeight: FontWeight.w600)),
          const SizedBox(height: 6),
          Text(value, style: const TextStyle(fontSize: 22, fontWeight: FontWeight.bold)),
        ],
      ),
    );
  }
}

ListView.builder: model থেকে তালিকা

Data থাকে model class-এর list-এ। ListView.builder শুধু পর্দায় দেখা row-গুলো বানায় — হাজার product-এও দ্রুত।

PHP/Laravel-এ যেমন Blade-এর @foreach ($products as $p) ≈ itemBuilder।
lib/main.dart
import 'package:flutter/material.dart';

void main() => runApp(const App());

class Product {
  const Product(this.name, this.brand, this.price, this.stock);
  final String name, brand;
  final int price, stock;
}

const products = [
  Product('Redmi 13', 'Xiaomi', 17500, 5),
  Product('Galaxy A15', 'Samsung', 21000, 0),
  Product('iPhone 12', 'Apple', 48000, 1),
  Product('Vivo Y28', 'Vivo', 18000, 4),
  Product('Walton NEXG N9', 'Walton', 9990, 7),
];

class App extends StatelessWidget {
  const App({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.green),
      home: Scaffold(
        appBar: AppBar(title: const Text('Products')),
        body: ListView.builder(
          itemCount: products.length,
          itemBuilder: (context, i) {
            final p = products[i];
            return ListTile(
              leading: const Icon(Icons.smartphone),
              title: Text(p.name),
              subtitle: Text(p.brand),
              trailing: p.stock == 0
                  ? const Chip(label: Text('শেষ'))
                  : Text('৳${p.price}', style: const TextStyle(fontWeight: FontWeight.bold)),
            );
          },
        ),
      ),
    );
  }
}

StatefulWidget আর setState

যে widget-এর ভিতরের মান বদলায়, সেটা StatefulWidget। মান বদলে setState() ডাকলে Flutter আবার build() চালায়। Screenshot নেওয়া হয়েছে + বাটন ৩ বার চাপার পর।

PHP/Laravel-এ যেমন Livewire-এ $this->qty++ করলে component আবার render হয় — একদম একই ভাবনা।
⚠️ setState ছাড়া শুধু _qty++ করলে মান বদলাবে কিন্তু পর্দা বদলাবে না।
lib/main.dart
import 'package:flutter/material.dart';

void main() => runApp(const App());

class App extends StatelessWidget {
  const App({super.key});

  @override
  Widget build(BuildContext context) => MaterialApp(
        debugShowCheckedModeBanner: false,
        theme: ThemeData(colorSchemeSeed: Colors.green),
        home: const CounterPage(),
      );
}

class CounterPage extends StatefulWidget {
  const CounterPage({super.key});

  @override
  State<CounterPage> createState() => _CounterPageState();
}

class _CounterPageState extends State<CounterPage> {
  int _qty = 1;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('পরিমাণ')),
      body: Center(
        child: Text('Charger × $_qty = ৳${650 * _qty}', style: const TextStyle(fontSize: 24)),
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: () => setState(() => _qty++),
        child: const Icon(Icons.add),
      ),
    );
  }
}

Form validation

Form + TextFormField-এর validator: ভুল হলে লেখা ফেরত দিন, ঠিক হলে null। Screenshot: খালি form-এ Save চাপার পর।

PHP/Laravel-এ যেমন 'name' => 'required', 'price' => 'integer|min:1' — একই নিয়ম, শুধু app-এর ভিতরে। Server-এ Laravel validation তবুও রাখুন।
lib/main.dart
import 'package:flutter/material.dart';

void main() => runApp(const App());

class App extends StatelessWidget {
  const App({super.key});

  @override
  Widget build(BuildContext context) => MaterialApp(
        debugShowCheckedModeBanner: false,
        theme: ThemeData(colorSchemeSeed: Colors.green),
        home: const ProductForm(),
      );
}

class ProductForm extends StatefulWidget {
  const ProductForm({super.key});

  @override
  State<ProductForm> createState() => _ProductFormState();
}

class _ProductFormState extends State<ProductForm> {
  final _form = GlobalKey<FormState>();

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Product যোগ')),
      body: Form(
        key: _form,
        child: ListView(
          padding: const EdgeInsets.all(20),
          children: [
            TextFormField(
              decoration: const InputDecoration(labelText: 'নাম'),
              validator: (v) => (v == null || v.trim().isEmpty) ? 'নাম দিতে হবে' : null,
            ),
            TextFormField(
              decoration: const InputDecoration(labelText: 'দাম'),
              keyboardType: TextInputType.number,

            ),
            const SizedBox(height: 20),
            FilledButton(onPressed: () => _form.currentState!.validate(), child: const Text('Save')),
          ],
        ),
      ),
    );
  }
}

import 'package:flutter/material.dart';
import 'package:provider/provider.dart';

class Cart extends ChangeNotifier {
  final _items = <String, int>{};
  int get count => _items.values.fold(0, (a, b) => a + b);
  int get total => _items.entries.fold(0, (s, e) => s + prices[e.key]! * e.value);
  void add(String name) {
    _items[name] = (_items[name] ?? 0) + 1;
    notifyListeners();
  }
}

const prices = {'Redmi 13': 17500, 'Charger 20W': 650, 'Cover': 250};

void main() => runApp(const App());

class App extends StatelessWidget {
  const App({super.key});

  @override
  Widget build(BuildContext context) => ChangeNotifierProvider(
        create: (_) => Cart(),

}

          ListTile(title: Text('মোট: ৳${cart.total}', style: const TextStyle(fontSize: 20, fontWeight: FontWeight.bold))),
        ],

API থেকে data: FutureBuilder

FutureBuilder একটা Future দেখে তিন অবস্থা আঁকে: লোড হচ্ছে, ভুল, data। API-টা Laravel বা এই সাইটের Rust Shop API-র মতো {"data": [...]} দেয়।

  • late final _future = ... — Future একবারই বানাই; build()-এর ভিতরে বানালে প্রতি redraw-এ নতুন request যেত
  • Screenshot-এর জন্য MockClient — নকল server; আসল app-এ http.Client()
  • Android-এ internet permission আর emulator থেকে PC-র server-এ যেতে 10.0.2.2
⚠️ Emulator থেকে localhost মানে emulator নিজেই, আপনার PC না। Laravel php artisan serve --host=0.0.0.0 চালিয়ে http://10.0.2.2:8000 দিন।
lib/main.dart
import 'dart:convert';
import 'package:flutter/material.dart';
import 'package:http/http.dart' as http;
import 'package:http/testing.dart';

class Product {
  Product.fromJson(Map<String, dynamic> j) : name = j['name'] as String, price = j['price'] as int;
  final String name;
  final int price;
}

class ProductApi {
  ProductApi(this.client, {this.baseUrl = 'https://api.example.com'});
  final http.Client client;
  final String baseUrl;

  Future<List<Product>> list() async {
    final res = await client.get(Uri.parse('$baseUrl/api/v1/products'));
    if (res.statusCode != 200) throw Exception('Server error ${res.statusCode}');
    final body = jsonDecode(res.body) as Map<String, dynamic>;
    return (body['data'] as List).map((j) => Product.fromJson(j as Map<String, dynamic>)).toList();
  }
}

// ডেমো: আসল app-এ লিখুন ProductApi(http.Client(), baseUrl: 'https://আপনার-api')
final demoApi = ProductApi(MockClient((req) async => http.Response(

    200, headers: {'content-type': 'application/json; charset=utf-8'})));

  State<ProductsPage> createState() => _ProductsPageState();
}

class _ProductsPageState extends State<ProductsPage> {
  late final Future<List<Product>> _future = widget.api.list();

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('API থেকে Products')),
      body: FutureBuilder<List<Product>>(
        future: _future,
        builder: (context, snap) {
          if (snap.connectionState != ConnectionState.done) {
            return const Center(child: CircularProgressIndicator());
          }
          if (snap.hasError) return Center(child: Text('ভুল: ${snap.error}'));
          return ListView(
            children: [
              for (final p in snap.data!) ListTile(leading: const Icon(Icons.cloud_done), title: Text(p.name), trailing: Text('৳${p.price}')),
            ],
          );
        },
      ),
    );
  }
}
