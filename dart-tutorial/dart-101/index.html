var, final, const

var — বদলানো যায়। final — একবারই মান দেওয়া যায়। const — compile-এর সময়েই জানা স্থির মান।

PHP/Laravel-এ যেমন PHP-র const VAT = 15; ≈ Dart const। final-এর মতো কিছু PHP-তে variable-এ নেই (PHP 8.1-এর readonly property কাছাকাছি)।
Dart
void main() {
  var balance = 500;        // type অনুমান: int
  balance = balance + 200;

  final shop = 'Rahim Mobile';      // একবারই
  const vatPercent = 15;           // compile-time স্থির

  print('$shop: balance $balance, VAT $vatPercent%');
}
আউটপুট
Rahim Mobile: balance 700, VAT 15%

void main() {

ভাগ: / আর ~/

Dart-এ / সবসময় double দেয় (PHP-র মতো)। পূর্ণসংখ্যার ভাগ চাইলে ~/।

void main() {

  print(7 % 2);      // 1

  print(int.parse('250') + 1);
  print(double.parse('99.5') * 2);
}

Null safety: ? আর ??

সাধারণ variable কখনো null হতে পারে না। null রাখতে চাইলে type-এর পরে ?। ব্যবহারের আগে Dart বাধ্য করে null সামলাতে।

PHP/Laravel-এ যেমন PHP-তে $phone->length null হলে চলার সময় error। Dart compile-এর সময়েই আটকায়। ?. হলো PHP 8-এর nullsafe ?->।
Dart
void main() {
  String? district;                 // null হতে পারে
  print(district ?? 'জানা নেই');     // PHP-র ?? একদম একই

  district = 'Sylhet';
  print(district.length);           // এখন নিশ্চিত, তাই চলে

  String? phone;
  print(phone?.length);             // null হলে null, error না
}
আউটপুট
জানা নেই
6
null
Dart
void main() {
  String? phone;
  print(phone.length);
}

main.dart:3:15: Error: Property 'length' cannot be accessed on 'String?' because it is potentially null.
Try accessing using ?. instead.

String: $ আর ${}

$name দিয়ে variable বসে, হিসাবের জন্য ${...}। তিনটা quote দিয়ে কয়েক লাইনের লেখা।

PHP/Laravel-এ যেমন PHP-র "Hi {$name}" ≈ Dart 'Hi ${name}'। পার্থক্য: Dart-এ single quote-এও interpolation চলে, আর জোড়া দিতে . না, + (বা interpolation)।
Dart
void main() {
  final name = 'Nusrat';
  final price = 650;
  final qty = 3;

  print('Customer: $name');
  print('মোট: ${price * qty} টাকা');
  print('নামের দৈর্ঘ্য: ${name.length}');

  final receipt = """
Rahim Mobile
------------
$name × $qty
""";
  print(receipt.trim());
  print('Redmi 13'.toUpperCase().contains('REDMI'));
}
আউটপুট
Customer: Nusrat
মোট: 1950 টাকা
নামের দৈর্ঘ্য: 6
Rahim Mobile
------------
Nusrat × 3
true

void main() {

  if (amount >= 1500) {

    print('ডেলিভারি ৬০ টাকা');

  print(label);
}

switch expression (Dart 3)

নতুন switch একটা মান ফেরত দেয়, => দিয়ে লেখা, _ মানে বাকি সব। PHP 8-এর match-এর মতোই।

Dart
String grade(int marks) => switch (marks) {
  >= 80 => 'A+',
  >= 70 => 'A',
  >= 60 => 'A-',
  >= 33 => 'পাস',
  _ => 'F',
};

void main() {
  for (final m in [95, 72, 48, 20]) {
    print('$m → ${grade(m)}');
  }
}
আউটপুট

72 → A
48 → পাস
20 → F
PHP-তে তুলনা
<?php
$m = 72;

Loop: for, for-in, while

PHP/Laravel-এ যেমন foreach ($cities as $city) → for (final city in cities)।

void main() {
  for (var i = 1; i <= 5; i++) {

  }

  var seconds = 3;
  while (seconds > 0) {
    print('$seconds...');
    seconds--;
  }
}

Function আর arrow

Return type নামের আগে। এক লাইনের function => দিয়ে।

PHP/Laravel-এ যেমন fn($a) => $a * 2 (PHP arrow function) ≈ Dart (a) => a * 2।
Dart
int totalPrice(int price, int qty) {
  return price * qty;
}

int withVat(int amount) => amount + amount * 15 ~/ 100;

void main() {
  final t = totalPrice(450, 4);
  print('মোট $t, VAT সহ ${withVat(t)}');
}
আউটপুট

Named আর optional parameter

{} দিয়ে named parameter — ডাকার সময় নাম লিখতে হয়, ক্রম লাগে না। required না দিলে ডিফল্ট মান বা ? লাগে। Flutter-এ সব জায়গায় এটা।

PHP/Laravel-এ যেমন PHP 8-এর named argument invoiceLine('Cover', qty: 2, price: 250) — Dart-এ একই লেখা!
Dart
String invoiceLine(String item, {required int price, int qty = 1, String? note}) {
  final line = '$item × $qty = ${price * qty}';
  return note == null ? line : '$line ($note)';
}

void main() {
  print(invoiceLine('Charger', price: 650));
  print(invoiceLine('Cover', qty: 2, price: 250, note: 'ছাড় ১০%'));
}
আউটপুট
Charger × 1 = 650
Cover × 2 = 500 (ছাড় ১০%)

Function variable-এ রাখা যায়, অন্য function-এ পাঠানো যায়। নামহীন function: (x) => ...।

int applyTwice(int Function(int) f, int value) => f(f(value));

void main() {

  print(applyTwice(addVat, 1000));

  final prices = [17500, 650, 21000];

Map: key → value

💡 stock['Redmi 13']! — শেষের ! মানে "আমি নিশ্চিত এটা null না"। ভুল হলে চলার সময় error, তাই কম ব্যবহার করুন।
Dart
void main() {
  final stock = <String, int>{
    'Redmi 13': 5,
    'Galaxy A15': 2,
  };
  stock['Vivo Y28'] = 4;
  stock['Redmi 13'] = stock['Redmi 13']! - 1;

  print(stock);
  print(stock['Nokia'] ?? 0);           // নেই → null → 0
  for (final entry in stock.entries) {
    print('${entry.key}: ${entry.value}টা');
  }
}

List-এ map, where, fold

Laravel Collection-এর মতো: where = filter, map = বদলানো, fold/reduce = যোগফল।

Dart
void main() {
  final prices = [17500, 650, 21000, 250, 9900];

  final expensive = prices.where((p) => p >= 5000).map((p) => p * 95 ~/ 100).toList();
  final total = prices.fold(0, (sum, p) => sum + p);

  print('দামি (৫% ছাড়): $expensive');
  print('মোট: $total');
  print('সবচেয়ে দামি: ${prices.reduce((a, b) => a > b ? a : b)}');
}
আউটপুট
দামি (৫% ছাড়): [16625, 19950, 9405]
মোট: 49300
সবচেয়ে দামি: 21000

Keyboard থেকে input

💡 int.tryParse ভুল লেখায় exception না দিয়ে null দেয় — null safety-র সাথে মিলিয়ে সুন্দর।
Dart
import 'dart:io';

void main() {
  stdout.write('কত কেজি চাল? ');
  final input = stdin.readLineSync() ?? '';
  final kg = int.tryParse(input.trim());

  if (kg == null) {
    print('সংখ্যা লিখুন');
    return;
  }
  print('$kg কেজি × ৭৫ = ${kg * 75} টাকা');
}
আউটপুট
ইনপুট: 12
কত কেজি চাল? 12 কেজি × ৭৫ = 900 টাকা

Project: টাকার নোট ভাঙানো

নিজে করুন একটা Map<int, int>-এ রাখুন কোন নোট কয়টা, শেষে map প্রিন্ট করুন।
Dart
import 'dart:io';

void main() {
  const notes = [1000, 500, 200, 100, 50, 20, 10, 5, 2, 1];
  stdout.write('কত টাকা ফেরত? ');
  var amount = int.tryParse(stdin.readLineSync()?.trim() ?? '') ?? 0;
  print('');

  var totalNotes = 0;
  for (final note in notes) {
    final count = amount ~/ note;
    if (count > 0) {
      print('${note.toString().padLeft(5)} টাকা × $count');
      amount %= note;
      totalNotes += count;
    }
  }
  print('মোট নোট: $totalNotes');
}

ইনপুট: 2785
