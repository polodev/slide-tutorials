Future: পরে আসবে এমন মান

Network বা file-এর মতো ধীর কাজ সাথে সাথে ফল দেয় না — দেয় একটা Future, মানে "পরে দেব"। await দিয়ে অপেক্ষা করি, আর function-এ async লিখি।

PHP/Laravel-এ যেমন PHP সাধারণত অপেক্ষার সময় পুরো request আটকে রাখে। Dart অপেক্ষার সময় অন্য কাজ (যেমন UI আঁকা) চালিয়ে যায় — এজন্যই Flutter app মসৃণ থাকে।
Dart
Future<int> fetchPrice(String model) async {
  await Future.delayed(const Duration(milliseconds: 300));   // ধরি API call
  return model == 'Redmi 13' ? 17500 : 21000;
}

Future<void> main() async {
  print('দাম খুঁজছি...');
  final price = await fetchPrice('Redmi 13');
  print('দাম: $price');
}

await না দিলে কী হয়?

await না দিলে Dart অপেক্ষা করে না — ২ নম্বর লাইন ৩-এর আগে ছাপা হলো। .then() পুরনো লেখার ধরন; নতুন কোডে await।

Dart
Future<String> load() async {
  await Future.delayed(const Duration(milliseconds: 100));
  return 'data এসেছে';
}

Future<void> main() async {
  print('১. শুরু');
  load().then((v) => print('৩. then পেল: $v'));   // অপেক্ষা করল না
  print('২. এই লাইন load শেষ হওয়ার আগেই চলল');
  final v = await load();                           // এখানে অপেক্ষা
  print('৪. await পেল: $v');
}

Future.wait: একসাথে কয়েকটা কাজ

তিনটা API একটার পর একটা ডাকলে সময় যোগ হয়। Future.wait দিয়ে একসাথে চালালে সময় লাগে সবচেয়ে ধীরটার সমান।

PHP/Laravel-এ যেমন Laravel-এর Http::pool() বা Concurrency::run()-এর মতো।
Dart
Future<int> branchSales(String branch, int ms) async {
  await Future.delayed(Duration(milliseconds: ms));
  return branch.length * 10000;
}

Future<void> main() async {
  final sw = Stopwatch()..start();
  final results = await Future.wait([
    branchSales('Mirpur', 300),
    branchSales('Uttara', 200),
    branchSales('Gulshan', 300),
  ]);
  final ms = (sw.elapsedMilliseconds / 100).round() * 100;
  print('$results → মোট ${results.reduce((a, b) => a + b)}');
  print('সময় ~$ms ms (৮০০ না!)');
}

Stream: একের পর এক আসা মান

Future একটা মান দেয়; Stream সময়ের সাথে অনেকগুলো — যেমন live বিক্রির খবর, chat message, GPS। async* আর yield দিয়ে বানাই, await for দিয়ে পড়ি।

Dart
Stream<String> liveSales() async* {
  for (final inv in ['INV-1001', 'INV-1002', 'INV-1003']) {
    await Future.delayed(const Duration(milliseconds: 100));
    yield inv;
  }
}

Future<void> main() async {
  await for (final inv in liveSales()) {
    print('নতুন বিক্রি: $inv');
  }
  print('stream শেষ');
}

StreamController আর listen

💡 Flutter-এ StreamBuilder widget এই stream শুনে UI নিজে থেকেই আপডেট করে।
Dart
import 'dart:async';

Future<void> main() async {
  final cart = StreamController<int>();
  var total = 0;

  final sub = cart.stream
      .where((price) => price > 0)
      .listen((price) {
        total += price;
        print('যোগ হলো $price → মোট $total');
      });

  cart.add(650);
  cart.add(-10);       // filter-এ বাদ
  cart.add(17500);
  await cart.close();
  await sub.asFuture<void>();
}
আউটপুট
যোগ হলো 650 → মোট 650

Isolate.run: ভারী কাজ আলাদা জায়গায়

Dart এক thread-এ চলে। বড় হিসাব (লাখ row-এর রিপোর্ট) মূল thread-এ করলে Flutter app আটকে যায়। Isolate.run কাজটা আলাদা isolate-এ পাঠায়।

PHP/Laravel-এ যেমন Laravel-এ ভারী কাজ queue job-এ পাঠান; Dart/Flutter-এ isolate। Flutter-এ compute() একই কাজের সহজ রূপ।
Dart
import 'dart:isolate';

int heavyReport(int n) {
  var sum = 0;
  for (var i = 1; i <= n; i++) {
    sum += i % 7;
  }
  return sum;
}

Future<void> main() async {
  final result = await Isolate.run(() => heavyReport(20000000));
  print('রিপোর্ট তৈরি: $result');
}

রিপোর্ট তৈরি: 60000003

JSON ↔ class: fromJson আর toJson

Map দিয়ে কাজ করলে typo ধরা পড়ে না। Model class বানিয়ে fromJson/toJson — Flutter app-এ প্রতিটি API response এভাবে।

💡 বড় project-এ json_serializable বা freezed package এই কোড নিজে লিখে দেয় (dart run build_runner build)।
Dart
import 'dart:convert';

class Product {
  Product({required this.id, required this.name, required this.price, this.stock = 0});
  final int id;
  final String name;
  final int price;
  final int stock;

  factory Product.fromJson(Map<String, dynamic> j) => Product(
        id: j['id'] as int,
        name: j['name'] as String,
        price: j['price'] as int,
        stock: (j['stock'] as int?) ?? 0,
      );

  Map<String, dynamic> toJson() => {'id': id, 'name': name, 'price': price, 'stock': stock};
}

void main() {
  const body = '[{"id":1,"name":"Redmi 13","price":17500,"stock":5},{"id":2,"name":"Galaxy A15","price":21000}]';
  final products = (jsonDecode(body) as List).map((j) => Product.fromJson(j)).toList();

  for (final p in products) {
    print('${p.name}: ${p.price} (স্টক ${p.stock})');
  }
  print(jsonEncode(products.first.toJson()));
}

Galaxy A15: 21000 (স্টক 0)

File পড়া আর লেখা

PHP/Laravel-এ যেমন file_put_contents() / file() → writeAsString() / readAsLines() — Dart-এ async।
Dart
import 'dart:io';

Future<void> main() async {
  final file = File('sales.csv');
  await file.writeAsString('invoice,total\nINV-1001,18150\nINV-1002,2100\n');

  final lines = await file.readAsLines();
  final total = lines.skip(1).map((l) => int.parse(l.split(',')[1])).reduce((a, b) => a + b);
  print('${lines.length - 1}টা invoice, মোট $total');

  await file.delete();
}

ছোট HTTP server আর client

dart:io দিয়েই server বানানো যায়। একই program-এ server চালু করে client দিয়ে call করি — কোনো package ছাড়া।

💡 Dart-এ backend লিখতে shelf বা dart_frog framework আছে। তবে Flutter app-এর backend সাধারণত Laravel বা Rust (এই সাইটের অন্য কোর্স)।
Dart
import 'dart:convert';
import 'dart:io';

Future<void> main() async {
  final server = await HttpServer.bind('127.0.0.1', 0);   // 0 = যেকোনো খালি port
  server.listen((req) {
    final body = req.uri.path == '/products'
        ? jsonEncode([{'name': 'Redmi 13', 'price': 17500}])
        : jsonEncode({'message': 'নেই'});
    req.response
      ..statusCode = req.uri.path == '/products' ? 200 : 404
      ..headers.contentType = ContentType.json
      ..write(body)
      ..close();
  });

  final client = HttpClient();
  for (final path in ['/products', '/orders']) {
    final res = await (await client.get('127.0.0.1', server.port, path)).close();
    print('GET $path → ${res.statusCode} ${await res.transform(utf8.decoder).join()}');
  }
  client.close();
  await server.close();
}
আউটপুট
GET /products → 200 [{"name":"Redmi 13","price":17500}]
GET /orders → 404 {"message":"নেই"}

import 'dart:convert';
import 'dart:io';
import 'package:http/http.dart' as http;

Future<void> main() async {

    ..headers.contentType = ContentType.json

Project: API থেকে রিপোর্ট

সব একসাথে: local server API হিসেবে, http দিয়ে data আনা, JSON → class, Future.wait দিয়ে তিন শাখা একসাথে।

নিজে করুন যে শাখার ফল আসতে ২০০ms-এর বেশি লাগে, সেটায় timeout দিয়ে "পরে চেষ্টা করুন" দেখান।
Dart
import 'dart:convert';
import 'dart:io';
import 'package:http/http.dart' as http;

class Sale {
  Sale.fromJson(Map<String, dynamic> j) : invoice = j['invoice'] as String, total = j['total'] as int;
  final String invoice;
  final int total;
}

const fakeDb = {
  'mirpur': [{'invoice': 'INV-1001', 'total': 18150}, {'invoice': 'INV-1005', 'total': 21300}],
  'uttara': [{'invoice': 'INV-1003', 'total': 24150}],
  'gulshan': [{'invoice': 'INV-1004', 'total': 48000}, {'invoice': 'INV-1008', 'total': 21650}],
};

Future<void> main() async {
  final server = await HttpServer.bind('127.0.0.1', 0);
  server.listen((r) {
    final branch = r.uri.pathSegments.last;
    r.response
      ..headers.contentType = ContentType.json
      ..write(jsonEncode(fakeDb[branch] ?? []))
      ..close();
  });
  final base = 'http://127.0.0.1:${server.port}/branches';

  Future<List<Sale>> load(String b) async {
    final res = await http.get(Uri.parse('$base/$b'));
    return (jsonDecode(res.body) as List).map((j) => Sale.fromJson(j)).toList();
  }

  final branches = fakeDb.keys.toList();
  final all = await Future.wait(branches.map(load));
  for (var i = 0; i < branches.length; i++) {
    final total = all[i].fold(0, (s, x) => s + x.total);
    print('${branches[i].padRight(8)} ${all[i].length}টা invoice  $total');
  }
  await server.close();
}
